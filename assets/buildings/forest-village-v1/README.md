# Runtime: лесные здания H01 / W01 / B01

Три GLB — точные копии [Blender-источников](../../../art/blender/forest-village-v1/README.md), метры, Godot Y-up, фасад +Z. Godot извлёк вложенные запечённые PNG; сохранять их и `.import` вместе с моделями. Это первые базовые материалы, не финальная художественная отделка.

`scripts/world/village_building_catalog.gd` задаёт положения демонстрации и размеры/входы. `village_building.gd` добавляет неподвижные коллизии и проход по ступеням, `village_door.gd` использует `entry_hinge` / `entry_leaf` и GLTF metadata `open_angle_degrees`. Сами GLB не редактируются для игрового состояния. Крыша остаётся видимой; лестницы, сундуки и очаг пока декорации.

[Проверки и воспроизведение 0.22.0](../../../docs/production/VILLAGE_GODOT_01_CHECKS.md). Новые адреса/сохранение/ключи требуют отдельной карточки; демонстрационные координаты не подменяют выбранный план деревни Б.
