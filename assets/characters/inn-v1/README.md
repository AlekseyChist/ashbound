# Люди ростовщика — цельные рисованные позы v1

Принятые облики D-114: вожак с усами в кафтане, бородатый здоровяк в жилете, молодой взрослый в кепке. Источник внешности: `local/previews/moneylender-thugs-art-01/thugs-concept-v1.png`. Производство — встроенный imagegen, 9 октября 2026; игровые атласы составлены из целых рисунков, без вращения частей и морфинга. Это не новая приёмка движения владельцем.

Каждый `thug_*_frames.tres` непосредственно использует одноимённый `thug_*-atlas.png`: 39 полных поз, 18 клипов. `idle/windup/attack/hit/guard × front/back/side` — по одному ключевому кадру; `walk × front/back/side` — по восемь последовательных фаз, обе половины шага. Guard подготовлен, текущий бой его не запрашивает. Side смотрит вправо, левый вид — отражение всего клипа.

Атлас: 4×10 ячеек384×384, последний слот пуст. Линия опоры378, `baseline_offset_pixels=186`. Упаковка каждой полной ячейки ×0.75, фиксированные переносы всей строки/ракурса; индивидуальная нормализация по bbox отсутствует. Порядок в атласе: пять действий по трём видам, затем walk front0–7, back0–7, side0–7. Скорость walk15поз/с; физика отдельно. Рантайм обязан читать конечные `pixel_size_walk_<view>` из TRES. Это не дополнительные коэффициенты масштаба.

Воспроизведение ресурсов из сохранённых игровых атласов: `python tools/build_inn_thug_frames.py --kind leader` (также brute/young). Атлас — канонический полный игровой рисунок; генератор не запускается при воспроизведении. Повторная сборка PNG из выбранных исходных листов: тот же скрипт с `--source-root <каталог>`; оригинальные листы, запросы и невыбранные варианты сохраняются локально по D-080. Неверные/обрезанные входы останавливают упаковку до изменения результата.
