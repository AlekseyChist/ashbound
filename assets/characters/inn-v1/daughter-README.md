# Inn-v1: дочь, этап боковой и задней ходьбы

Цельные рисунки Codex/imagegen по принятому облику D-111 и направлению D-114/передачам071,076,079. Это собственный игровой арт AshBound; сторонние рисунки/модели не включены. Герой использован как опора движения/стиля, его ассеты не менялись.

`daughter_walk_side_frames.tres` и `daughter_walk_back_frames.tres` содержат по одному клипу walk_side/walk_back, по8кадров15fps, loop=true. Это ресурсы проверки, не полный `daughter_frames.tres` и не замена inn-temp в PR168. Другие действия/ракурсы и художественная приёмка в зале не завершены. Left отражает весь side-клип; внутри циклов отражений нет. Этот Codex владеет daughter*, второй — thug_*; README назван отдельно по081.

Игровой `daughter-walk-side.png` — одновременно сохраняемый исходник восьми цельных поз: RGBA1536×1024, четыре столбца/два ряда, ячейка384×512. Все фигуры сохранены целиком, без изменений головы/конечностей и индивидуального масштабирования. Из выбранного raw walk-side-v2 перенесён целиком нижний ряд на40px вниз; верхний ряд без переноса. Исходная проба, точный запрос, упаковщик и отчёты находятся в основной папке `local/previews/inn-daughter-animation-01/` и `local/qa/inn-daughter-animation-01/`; игровые PNG не зависят от наличия этих отчётов.

Общая опора504px от верха ячейки, `baseline_offset_pixels=248`; рабочий `pixel_size_walk_side=1.70/410=0.004146341463414635`, один на весь цикл. Это соответствует контракту1.70м с Claude079; не дополнительный множитель в упаковке/runtime. Все кадры source0..7 читаются по строкам. Боковая ходьба содержит контакт/опору/проход/подготовку противоположного контакта обеих половин; качество шва и пропорций оценивается отдельно от технических тестов.

Ресурс воспроизводится из сохраняемого PNG стандартным Python: `python assets/characters/inn-v1/build_daughter_walk_side.py`. Сборщик проверяет неизменность atlas и создаёт только TRES; повторная генерация AI не является воспроизводимой сборкой. Атлас реально загружается ресурсом и проверкой `scripts/tools/validate_inn_daughter_walk.gd`.

Задняя ходьба: source back-v6, цельные позы по принятому back-листу героя с женской анатомией/принятым костюмом. Один перенос(0,+8) на весь клип, линия ног504/baseline248; общий pixel_size_walk_back=1.70/482. В сохраняемом daughter-walk-back.png все видимые рисунки целы; отрезанные пиксели с alpha1 ниже штатного discard0.25. Контакты0/4 меняют ведущую ногу, руки идут противофазно; ранние v4/v5 не входят в игру. Тот же stdlib-сборщик воспроизводит оба TRES, фиксируя SHA каждого PNG; side ресурс не изменён. Изолированный реальный импорт/normal/slow back и side проверены, но визуальная приёмка всей сцены остаётся отдельной.

Проверки: см. описание текущего draft PR. PNG/логи/GIF проверок — только local/ по D-080. Полную кампанию, APK/S23, FPS и личную художественную оценку владельца по этому этапу не заявлять.
