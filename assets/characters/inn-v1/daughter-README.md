# Inn-v1 — дочь трактирщика, полный первый набор r01

Собственные цельные рисунки Codex/imagegen по принятому облику D-111 и направлению D-114/071/076/079. Сторонние ассеты не включены; принятый герой использован как опора стиля/фаз, его файлы не менялись. Этот Codex владеет daughter*, другой — thug_*; Claude — игровой код/интеграцию PR168 по081.

Игровой ресурс `daughter_frames.tres`:24клипа idle/walk/run/windup/attack/hit/out/guard ×front/back/side;66цельных поз. Walk/run по8фаз15fps, порядок0..7 конечного атласа; idle и боевые состояния по1ключевой позе. Idle/walk/run loop=true, боевые loop=false; удержание боевых ключей задаёт runtime. Down/getup не входят в контракт. Left — отражение всего готового side-клипа, не способ получить вторую половину шага.

Шесть motion-PNG1536×1024 (4×2) и daughter-states.png1152×3072 (3вида×6действий) сохраняют выбранные цельные рисунки как канонические RGBA-исходники игрового набора. Все конечные ячейки384×512, линия ног504, baseline_offset_pixels248; один pixel_size на все фазы клипа. Оригинальные запросы/невыбранные варианты/упаковка/QA только main/local/previews/inn-daughter-animation-01 и main/local/qa/inn-daughter-animation-01 по D-080. Игровая сборка и восстановление TRES от них не зависят.

`python assets/characters/inn-v1/build_daughter.py` стандартной библиотекой проверяет SHA всех7сохранённых PNG и воспроизводит TRES. Повторная генерация AI не воспроизводима. Фиксированные масштабы, порядок и SHA закреплены в сборщике; изменившийся вход останавливает сборку до записи ресурса. Параметры импорта сохраняют RGBA/альфа-границы и отключают mipmaps.

Упаковка: целые ячейки, без частей/куклы/индивидуального zoom/масок. Side walk нижний ряд+40;front walk верх−4/низ+6;back walk все+8. Front run верх−4/низ+20;back run верх+7/низ+33;side run верх+17/низ+40. Для front/back run источник читается4..7,0..3, чтобы ведущая нога контакта0 совпала с walk; готовые PNG0..7. Полётные кадры не выравниваются по bbox/ногам. Все18одиночных state-ячеек равномерно уменьшены×0.75; каждой целой однофазной ячейке назначен фиксированный якорь подошв из карточки, общий масштаб на все6состояний вида.

Техническая проверка: `Godot --headless --path . --script scripts/tools/validate_inn_daughter_frames.gd` после импорта. НаПК Godot4.7.2:24клипа/66поз/поля/опора/масштаб проверены, failures0; GPU normal/slow во всех3видах,по3цикла walk+run и боевые позы в общей камере рядом с героем. Это собственный QA, не независимое ревью и не художественная приёмка владельца.

Перед подключением Claude получает точный коммит; после — отдельный осмотр настоящего зала/боя, ожидания после загрузки/ночи и посадки всех четырёх на пол по082. APK/S23/FPS, полный маршрут и художественная оценка пока не выполнены; PR170 остаётся draft.
