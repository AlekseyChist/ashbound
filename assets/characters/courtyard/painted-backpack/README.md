# Цельные кадры путешественника с рюкзаком

**Текущий набор — 0.15.2, `*-v2.png`:** 84 цельные позы в семи прозрачных атласах 1254×1254. Сохранены исходные пропорции головы и тела; надевание рюкзака больше не расширяет персонажа. [Арт-исходники, разрешённая владельцем обработка и повторение](../../../../art/characters/backpack-width-v2/README.md), [проверки ПК/S23](../../../../docs/production/BACKPACK_PROPORTIONS_CHECKS.md). Оригинальные парные листы без рюкзака не изменены. Передний v2-лист содержит все четыре кадра покоя и не требует отдельной коррекции. Игровые SpriteFrames и экспорт используют v2; прежние PNG остаются исходниками и историей.

Ниже — состав исходного набора 0.8.1, ART-SPRITE-01, заменённого версией v2:

| Лист | Используемое покрытие |
| --- | --- |
| traveler-back-pack.png | Спина: 8 ходьбы, 4 покоя, 4 удара |
| traveler-front-pack.png | Лицо: 8 ходьбы, 3 покоя, 4 удара |
| traveler-front-idle-correction.png | Только idle_front[2]; остальные рисунки листа не используются |
| traveler-side-pack.png | Правый бок: 8 ходьбы, 4 покоя, 4 удара |
| traveler-run-back-pack.png | 8 кадров бега со спины |
| traveler-run-front-pack.png | 8 кадров бега лицом |
| traveler-run-side-pack.png | 8 кадров бега боком |
| traveler-pocket-pack.png | 4 кадра жеста кармана × спина/лицо/бок |

Симметричный безоружный левый бок получается отражением правого. Для асимметричного оружия это не разрешение зеркалить ведущую руку или ножны.

Сборщик: [build_painted_backpack_frames.gd](../../../../scripts/tools/build_painted_backpack_frames.gd). Выходы: [основные клипы](../traveler_backpack_frames.tres) и [карман](../traveler_backpack_pocket_frames.tres). Полный кадр выбирается по настоящей экипировке, отдельного аксессуара поверх тела нет. Масштаб, виртуальное полотно, фазы и длительности сохраняются.

[Промпты и происхождение 0.8.1](PROMPTS.md) · [исторические проверки 0.8.1](../../../../docs/production/PAINTED_BACKPACK_CHECKS.md). Генерация — встроенный imagegen, не CLI. Прежние исходные PNG сохранены без изменений; их производные v2 прошли точную обработку пикселей по разрешению владельца. AtlasTexture выбирает область и опору; отдельный корректирующий лист больше не экспортируется.
