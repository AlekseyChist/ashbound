# Волк и стражник: первый боевой стенд

22 сентября 2026. Рисунки созданы ImageGen для AshBound по запросу владельца: волк прыгает и кусает, стражник дерётся кулаками. Это цельные 2D-позы для существующего 3D-двора, без отдельных аксессуаров в игре.

`wolf.png` и `guard.png` — исходные прозрачные листы 1254×1254. Три столбца: спереди, сзади, правый бок; левый бок зеркалится. Шесть строк: стойка, два шага, подготовка, удар/укус, реакция. Стражник в оливковой рубахе и коричневом кожаном жилете; волк серо-коричневый. Художественные ориентиры: рисованный путешественник и жители двора, выразительные редкие позы, неизменные одежда/окрас между действиями.

Исходные запросы требовали 18 раздельных полных силуэтов, прозрачного фона, одинаковой палитры и масштаба, без текста/оружия/теней окружения. Полученные листы имеют неравномерные интервалы, поэтому нарезка по равным клеткам непригодна.

Игровой сборщик локальной Ollama: `scripts/tools/build_corner_enemy_frames.gd`. Он выделяет восемь-связные компоненты alpha > 0.12, проверяет ровно 18 крупных силуэтов на лист и переносит их RGBA без изменения масштаба/цвета в клетки 512×512. Мелкие отделённые частицы < 1800 пикселей исключены. Итоговые атласы 1536×3072. Опора в клетке y=492; для выпада волка дополнительно 12 пикселей воздуха. Высота стойки: волк 1 м, стражник 1,85 м; масштаб фиксирован для ракурса и не пересчитывается по размеру каждой позы.

Два прохода в отдельной копии проекта:

```text
godot --headless --path PROJECT --script res://scripts/tools/build_corner_enemy_frames.gd
godot --headless --path PROJECT --editor --import --quit
godot --headless --path PROJECT --script res://scripts/tools/build_corner_enemy_frames.gd -- --with-frames
```

Первый проход пишет PNG и промежуточный manifest; второй создаёт SpriteFrames после импорта текстур. Исходные хеши и конечные размеры записаны в `build-manifest.txt`. Обе исходные картинки проверяются до записи атласов; это не транзакционная система отката при сбое диска во время записи.

Независимый Codex QA: `tools/validate_corner_enemy_art.py` — 36 поз, 631 152 точных RGBA-пикселя, отсутствие соседних фрагментов/обрезания/растяжения, два отрицательных контроля. `tools/check_corner_enemy_builder.py` — четыре отказных случая без частичной перезаписи, повторяемость PNG и pack-manifest. Внешний вид проверен в игре с четырёх направлений камеры. Это первый набор для проверки боя, не финальная художественная приёмка владельцем.
