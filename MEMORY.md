## Лор, план и статус идей

Исходный мир: разрушенное королевство, безымянный бродяга, Орден Пепельного Пламени, Конклав Чародеев, Совет Наместников, разобщённые Изгнанники и пробуждающаяся разумная древняя раса. Текст владельца сохранён без изменений в [LORE_ORIGINAL.txt](docs/narrative/LORE_ORIGINAL.txt).

Подготовлен **черновик v0.1**, новые детали которого ещё не объявлены окончательным каноном: люди разбирают древнюю защиту мира ради выживания; завязка с пропавшим обозом в Чёрной переправе; пять актов и три семейства финалов. Поручение сохранить материалы в Git само по себе не утверждает каждый сюжетный поворот.

Предложен первый законченный эпизод на 30–45 минут: пять именованных NPC, три задания, один выбор о распределении зерна с двумя последствиями. Полная игровая цепочка, сенсорный интерфейс и этот эпизод ещё не реализованы. В исходниках уже есть заготовки игровых систем; их наличие не является подтверждением готовности.

## Откуда продолжать

1. Прочитать [состояние и очередь](docs/production/STATUS.md): текущий этап M1, следующая содержательная задача NAR-01 — разбор сюжетного ядра с владельцем.
2. Для сюжета использовать [сюжетную основу](docs/narrative/STORY_BIBLE.md) и [первый эпизод](docs/narrative/PROLOGUE.md).
3. Порядок производства: сюжетное ядро → прототип управления и игрового цикла на двух платформах → сохранённый выбор → законченная Переправа → определение размера кампании → производство → альфа → бета → выпуск. Критерии: [ROADMAP.md](docs/production/ROADMAP.md).
4. Инструменты после нового клонирования восстановить по [tools/README.md](tools/README.md). Исполняемые программы, веса модели и журналы `.tools/` в Git не хранятся.

После новых решений обновлять этот краткий контекст и подробный статус. Различать предложения, согласованные решения, написанный код и действительно проверенное поведение. Новое прямое указание владельца имеет приоритет над планом.
