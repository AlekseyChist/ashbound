# Карточка ограниченной задачи

Копировать для каждой задачи CONS и последующей разработки. Карточка может находиться в UTF-8 файле задания `.tools/ollama-godot/tasks/`; её результат и устойчивые решения сохраняются в Git через STATUS/протокол. Перед выдачей Ollama сверить каждый интерфейс с актуальным исходником. Пустые обязательные поля означают, что задание ещё не готово к исполнению.

```text
ID и место в очереди:
Игровой результат одним предложением:
Основание: поручение владельца / пункт плана / воспроизведённая ошибка:
Исходный коммит dev и новая ветка codex/...:

Входит в задачу:
Не входит; поведение и данные, которые сохраняем:
Разрешённые для изменения файлы:
Существующие интерфейсы: файл, класс/метод, сигнатура, значимые ограничения:
Контекст для чтения и точные опорные фрагменты:
Визуальный эталон и конкретные изображения (если есть визуальное изменение):
EN/RU и сохранения (затрагиваются / нет, почему):

Критерии готовности — наблюдаемые результаты:
План независимой проверки Codex: обычный путь, границы, отказ, регрессии:
Проверяемые платформы, ввод и способ сверить установленный билд:
Нужна ли личная оценка: что именно сравнивается и как показать результат:

Исполнитель: установленная локальная Qwen через Ollama; Codex — основные тесты:
При невозможности выполнить: конкретный отсутствующий интерфейс/контекст,
ошибка или необходимое расширение scope; не выдумывать API и не менять
файлы вне задания. Исправление выдаётся отдельным ограниченным поручением.

После исполнения заполняет Codex:
Фактический diff и отклонения от задания:
Результаты проверок, журналы/снимки, версии/хеши сборок:
Что проверено лично владельцем и что остаётся открытым:
PR в dev, проверенный head, слияние, обновление dev, удаление ветки:
Следующий ограниченный шаг:
```

Начинать новый ограниченный вызов локального исполнителя с актуальными файлами и результатами предыдущей проверки. Не переносить всю историю обсуждения вместо точного контекста. При повторной ошибке сначала пересмотреть воспроизведение и контракт задания; не наращивать цепочку случайных правок. Сообщение модели об успехе не является результатом независимой проверки.
