# INN-BRAWL-01 — утро в трактире: люди ростовщика и первая драка с дочкой

```text
ID и место в очереди: INN-BRAWL-01, STATUS «Трактир дальше», после INN-REST-01.
Для участка мира: новой планировки нет — сцена в существующем зале лесного трактира T03A.
Игровой результат: наутро после первой ночи в трактире внизу трое людей ростовщика пристают
  к дочке трактирщика; герой выбирает ответ, вместе с дочкой даёт им отпор (или очнётся на
  койке после поражения) и получает постоянную койку.
Основание: поручение владельца 3 октября 2026 «давай доделаем этот квест»; D-092, D-093,
  глава #141 ред. 2 (D-111/112/113, docs/design/INN_STORY_01_PROPOSAL.md).
Исходный коммит: dev 88f5777, ветка claude/inn-brawl-01.
Исполнитель: Claude по прямому поручению владельца (Codex занят рисунками дочки и людей
  ростовщика по 069). Визуальная проверка сцены — Codex по правилам совместной работы.

Входит:
- состояние главы в файле трактира (user://world_inn.cfg): none → pending (после сна) → done;
  постоянная койка (owned): сон её не забирает, аренда больше не предлагается;
- постановка в зале: трое у стола у выхода, дочь с подносом, трактирщик за стойкой;
- спуск героя в зал запускает реплики, затем выбор из трёх ответов (DialogueChoices);
  «Я только спустился» — без драки, выбор предлагается снова у стола;
- драка: трое — враги «guard» общей сессии боя (блок/удар героя как с волками); дочь — союзник,
  сходится с крепышом; сбитая дочь выбывает до конца (отходит к стойке); враг после нескольких
  ударов сдаётся и уходит в дверь; первый сдавшийся уводит остальных; вожак грозит «хозяин узнает»;
- поражение героя (пробно 6 пропущенных ударов за драку): затемнение, трое ушли, герой на своей
  койке, реплики дочки и трактирщика, койка своя;
- уход из трактира или перезапуск посреди драки — сцена возвращается к состоянию перед дракой;
- реплики EN/RU, цель в журнале «Внизу шумно».

Не входит / сохраняем: общая система здоровья (HEALTH-01), полоски здоровья, смерть, тяжёлый
  нокаут, сундук (INN-CHEST-01), ростовщик и должник, новые техники боя. Облики — временные:
  трое и дочь используют рисунок стражника (guard_frames) с подписью над головой до кадров
  Codex по D-111/D-112. Волки, урок сторожа, аренда и сон без изменений.

Файлы: scripts/world/inn_brawl.gd (новый), scripts/world/inn_brawl_ally.gd (новый),
  scripts/world/inn_lodging.gd, scripts/world/world.gd (подключение, журнал, меню трактирщика),
  scripts/combat/corner_enemy_actor.gd (необязательные поля: противник, радиусы, точка ухода,
  подпись — по умолчанию прежнее поведение), localization/{en,ru}.po, messages.pot,
  scripts/tools/validate_inn_brawl.{gd,tscn}, эта карточка, STATUS.

Критерии готовности:
- после первого сна сцена ждёт внизу; до спуска никто не нападает;
- три ответа работают; деньги не списываются; «Я только спустился» не даёт койку;
- в драке враги бьют героя, крепыш — дочь; блок героя работает; удары героя и дочки гонят врагов;
- победа и поражение дают одну постоянную койку, повторной драки нет;
- уход/перезапуск в драке не теряют сцену и не дают двойной награды;
- сохранение главы и койки переживает перезапуск; старый файл трактира читается;
- прежние проверки трактира, мира и боя с волками не ломаются; EN/RU без пропусков.

Проверки: новый validate_inn_brawl (настоящая сцена мира, реальные удары/блок), validate_forest_inn,
  validate_world_village, локализация; затем сборка ПК, ручной проход владельца; визуальный
  осмотр зала в движении — Codex.
```
