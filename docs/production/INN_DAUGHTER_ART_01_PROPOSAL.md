## Сохранённый игровой контракт
Idle/walk/run/windup/attack/hit/out/guard ×front/back/side. Walk/run8фаз15fps, loop; idle1ключ loop=true; боевые1ключ loop=false, время удержания runtime Claude. Down/getup не заказаны; out держится за повреждённую руку. Конечная ячейка384×512, baseline248, подошвы504. Все7PNG — канонические сохраняемые цельные RGBA-исходники, реально используемые полным TRES. Старые два частичных TRES/сборщик/валидатор заменены полным набором.

Сборщик build_daughter.py закрепляет SHA, последовательность0..7, один pixel_size для всего клипа и воспроизводит TRES стандартным Python без местных отчётов/генератора. Перед записью проверяет все7входов. Мета pixel_size_action_view, fallback pixel_size_view; повторного множителя масштаба в runtime нет. Высота опоры соответствует1.70м; наклон/присед/полёт не выравниваются по общему bbox.
