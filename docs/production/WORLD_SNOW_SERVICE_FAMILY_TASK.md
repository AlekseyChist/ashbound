# Семь модулей служб снежного города

Основание: утверждённая PDF141 и точные участки D-118. Ветка codex/snow-service-family от1201616; PR192, draft. Один результат: семь пригодных модулей для11 участков, без растягивания чужой модели под пятно.

## Состав и границы

- Б1–4: казарма11×5; Б10–11: казарма10×5.
- л1/л2/л3: сапожник, шорник, свечник7×5 с различимыми товарами и вывесками.
- Пд: постоялый двор12×7; Др: открытый дровяник6×4 без придуманной двери/лампы.
- Холодные казармы из дерева, тёплые службы с известковой штукатуркой, тёмным деревом/сланцем, физическими дымоходами. Проходы, кровати взрослого размера, обычные двери и лампы сохраняются.
- Генератор build_snow_service_family.py, семь GLB и сцен, snow_service_building.gd, независимый validate_snow_service_family.gd и эта карточка. Расстановка/рельеф/world.gd остаются Claude. Никаких новых систем услуг/NPC/планировки.

## Открытый художественный возврат

1. Эмблемы сапога/седла сливаются с тёмной доской — нужен читаемый контраст краски в прежнем свете.
2. Три прямоугольника на сушилке не читаются рубахой/плащом/штанами; нужны силуэты одежды и перегиб через перекладину.
3. Кольца ремней висят без крепления на7,5см ниже верхней полки — нужны опирающиеся крючки.
4. Свечным связкам нужен видимый фитиль/подвес до прута.

Один ограниченный возврат отправлен Claude для локальной Qwen. Текстура печи/цоколь приняты как улучшение; вся художественная редакция пока не принята. PR остаётся draft.
