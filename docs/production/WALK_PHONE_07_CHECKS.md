# WALK-PHONE-07 — тест на S23

23 сентября 2026. По просьбе владельца подготовлено и открыто отдельное приложение **AshBound Walk Preview 0.19.4-walk-preview, code49**, `org.ashbound.walkpreview`. Новая ходьба WALK-POSE-06 и выбранный масштаб MOTION-SCALE-05 применяются только в экспортной копии. Исходные игровые ресурсы, прежний Forest Route 0.19.3, кампания и боевой стенд сохраняются.

## Состав и воспроизведение

`node tools/build-forest-route.mjs --walk-preview --baseline-root C:/Users/prost/Documents/AshBound`

Сборщик копирует готовый `art/characters/walk-consistency-v1/walk-atlas.png` в отдельный staged asset. В staged `traveler_frames.tres` изменены только ссылка walk/walk_side и четыре метаданных масштаба: side walk ×0.95, side run ×0.9, front/back run ÷0.9. Размер/порядок кадров, остальные клипы, baseline 182, физика, ввод, UI и код игры прежние. Новое приложение имеет отдельный каталог настроек; при первом запуске используется штатный выбор языка устройства (на этом S23 показан EN).

Codex выполнил упаковку и отдельный проход QA. Нового игрового кода и поручений Qwen в этой задаче нет. Границы — [карточка](WALK_PHONE_07_TASK.md).

## Проверено

- Импорт Godot 4.7.2, Android и Windows export: exit0, без SCRIPT ERROR/ошибок движка.
- Графическая проверка на ПК: `res://scripts/tools/validate_walk_phone.tscn` в экспортной копии, 8 завершённых сценариев walk/run × right/left/front/back, пустой список failures, `ASHBOUND_WALK_PHONE_OK cases=8`. Реально проиграны полные циклы и переход через последний кадр, проверены источники нового атласа, порядок поз, масштаб/опора, отражение, скорость 4.2/6.4, возврат idle и сброс.
- Samsung S23 SM_S911B, `RFCX11JX0PW`: установка Success, холодный запуск Status ok; versionName/code и SHA-256 установленного base.apk совпадают с собранной APK. На снимке после запуска видны сцена и активный боковой бег. В журнале процесса ошибок не найдено.
- На телефоне **автоматических касаний не выполнялось**: сразу после запуска на снимке уже были активны Run и правая стрелка, что указывало на начавшуюся ручную проверку. Приложение оставлено владельцу. Отдельный автоматический сценарий касаний, атаки и Home/resume на S23 не заявляется пройденным.

Последующий отзыв владельца, 23 сентября: движение в этом приложении лично принято на S23 (D-059). [Сохранённый эталон и рецепт](../../art/characters/accepted-traveler-v1/README.md). Это художественная приёмка показанного движения, не остальных действий/будущих сетов. OnePlus не подключён. Это отдельный лесной макет, не интеграция в кампанию.
