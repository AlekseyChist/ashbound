# VILLAGE-FOREST-KIT-01 — окружение тестовой деревни

24 сентября 2026, D-072. Владелец после схемы Б v1.1 и плана погоды поручил собрать деревню для теста, проверить модели окружения включая деревья, подключить свет/сутки/погоду. Направление: Gothic, насыщенные природные цвета, глубокие тени, тёмные места действительно тёмные. Это разрешение на тестовую сборку по показанной схеме; художественная оценка готовой картинки впереди.

Первый ограниченный результат: воспроизводимый набор лесного окружения для следующей сборки деревни. База `6c2dd3c33a4689775a070e0d912ef53a0f5403fb`, новая ветка `codex/village-forest-kit`. Затем отдельно VILLAGE-ASSEMBLY-01 и VILLAGE-ATMOSPHERE-01, последовательными PR; основной игровой мир/CONS не объявлять завершёнными.

Аудит: H01/W01/B01 с интерьером, колодец `assets/buildings/ashbound/courtyard_well.glb`, ограды/бочки/ящики уже есть. Прежний лес Forest Route — геометрический blockout; финальный хвойный набор отсутствует. Нужны сосны/ели с видимыми ветвями и нерегулярным силуэтом, камень, пень, куст/папоротник, трава.

Исполнитель Blender-геометрии: локальная Qwen, установленная `qwen3.8-24k:latest`; Codex готовит контракт, запускает Blender, проверяет геометрию/GLB и визуальный результат. Разрешены `art/blender/village_forest_kit.py`, `art/blender/village-forest-v1/**`, `art/previews/village-forest-v1/**`, `assets/environment/village-forest-v1/**`, эта карточка/проверки и актуальные MEMORY/STATUS/ROADMAP/docs README. Изменения подтверждения Б v1.1 — только отдельный DECISION.md и ссылка из README; исходный лист остаётся историческим образцом.

Контракт нового набора: метры, основание в начале координат, GLB Y-up после экспорта Blender; foliage/bark/stone роли, не более 5000 треугольников на дерево, до 3 материалов/mesh, без камер/света в экспорте. Стабильные имена и seed. Исходный BLEND, GLB, статистика и рендеры. Сложный ветер/освещение — следующая карточка, не код локальной модели в этом шаге.

QA Codex: самостоятельная проверка размеров/полигонов/материалов/конечных координат, импорта всех GLB в Godot, сравнение набора с домами, сохранность принятых спрайтов и старых ресурсов. Сам ответ модели не приёмка. Это ассетный шаг без новой игровой сборки; интеграция и ПК/телефон обязательны следующими шагами до передачи владельцу. S23 подключён по ADB при начале работы. Новых действий/текстов UI нет.

## Результат

Первый ответ Ollama оборван с invalid tool call JSON; после сокращения до трёх деревьев получен скрипт. Реальный запуск выявил пустой выбор экспорта. Один возврат Qwen исправил часть ошибок, но ветви всё ещё попали в foliage и цвета покрывали не все вершины. Codex принял остаточную отладку после этого возврата по D-047: исправил принадлежность геометрии и полный массив ветровых весов. Художественный результат и экспорт ещё проверяются.


**Итог QA:** семь GLB импортированы Godot 4.7.2 Mobile без ошибок; геометрия/размеры/бюджеты проверены собственными проверками Codex. Повторная сборка дала одинаковые SHA всех семи GLB. Сравнение деревьев/растений рядом с H01 сохранено в art/previews/village-forest-v1/kit-with-house.png; принятые 40 файлов героя неизменны. На первом проходе исправлена ошибка самого QA (обращение global_transform до входа в дерево), затем полный повтор пройден без ошибок. Новая APK на этом ассетном шаге не создавалась. Следующий шаг после PR — VILLAGE-ASSEMBLY-01, без дополнительного ожидания разрешения по D-072.
