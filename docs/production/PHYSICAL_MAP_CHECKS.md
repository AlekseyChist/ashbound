# MENU-02C / MAP-01A — физическая схема двора

21 сентября 2026. Ветка `codex/physical-courtyard-map` от `dev` после PR #30. Локальная `qwen3.8-24k:latest` пишет игровые компоненты и сцены; Codex готовит независимые проверки и выполняет приёмку.

## Объём

Первый прототип ограничен уже существующим учебным двором. Рисованная схема показывает дом, ворота, башню, колодец, поленницу и мишень. Она лежит на ящике у дома: герой должен сам взять её, потратив место в носимом хранилище, и может положить обратно. Стартовый инвентарь остаётся пустым. Это локальный предмет прототипа; способ получения первой карты мира в сюжетной кампании ещё проектируется.

Раздел «Карта / Map» общего меню доступен только с настоящим предметом в доступном кармане или надетом хранилище. Картинка или произвольная настроенная ёмкость не считаются владением. Изъятие последней доступной копии очищает рисунок и возвращает раздел вещей. Доступ проверяется при выборе, изменении предметов/размещения и загрузке снимка, а не запоминается после первого просмотра.

На рисунке нет переводимого текста, маркера героя, мини-карты или выдуманных земель. Название и описание — отдельные строки EN/RU. Изображение — художественная схема ориентиров, не метрический план и не утверждённая география мира.

## Границы

Файловое сохранение кампании остаётся SAVE-01. API инвентаря проверяется через типизированный снимок после `var_to_bytes`/`bytes_to_var`; JSON-адаптер этим API не предусмотрен (его числа становятся float). Состояние единственного листа на ящике пока живёт в сцене. Повторный старт учебного задания внутри сцены не создаёт новую копию. Ящик допускает возврат одного листа; неоднозначный возврат нескольких тестовых копий отвергается. Домашние сундуки, полноценная торговля картами, масштабирование и несколько регионов не входят в этот этап.

## Проверки

Независимый `validate_physical_map.gd` завершил десять групп: пустой старт и запрет обхода вкладки, получение через реальный ввод E и защита повторного входа из сигнала, EN/RU и размеры кнопок/рисунка, немедленное изъятие и типизированный снимок, ненадетое хранилище, настоящий рюкзак, потеря кармана/возврат листа, полный карман с повторной попыткой, перезапуск задания и несколько копий. Проверяются сохранность вещей, денег и квеста при чтении/отказах и обязательный жест до меню.

Во время разработки Codex обнаружил ошибки API в первой реализации Ollama и вернул их локальной модели; исправления перечитаны. Первая версия самого теста ошибочно использовала JSON вместо документированного типизированного API Inventory; тест исправлен на `var_to_bytes`/`bytes_to_var` без ослабления ожиданий. Расширение JSON-загрузчика в игровой код не вносилось.

Все **23 основных набора PASS**, десять групп карты PASS отдельно в headless и графическом режиме; каталоги **107 ключей EN/RU PASS**, `git diff --check` PASS. В графическом тесте ожидание скорректировано на завершённый цикл `_process`, поскольку сигнал `process_frame` приходит до обработки узлов, а несколько физических шагов могут приходиться на один кадр. Ожидания результата не ослаблялись. Новых предупреждений движка у карты нет; при общем импорте остаются прежние предупреждения старой FBX-сцены/объёмного тумана.

Изображение и размеры просмотрены: ПК RU, ПК EN. Четыре вкладки, заголовок, рисунок, подпись ориентиров и выбор языка помещаются в окно. Рисунок создан встроенным imagegen: [PNG](../../assets/ui/maps/courtyard-sketch-v1.png), [точный запрос и происхождение](../../assets/ui/maps/PROMPTS.md).

В обычной игре Codex проверил: пустой старт → недоступная карта → подход к ящику → получение через «Действие» → предмет в кармане → карта RU/EN → Back → возврат листа → пустой карман и недоступная вкладка → повторное получение → Home/возврат → повторное открытие той же карты. Ошибок скриптов, движка и аварий в журнале процесса нет. После фона меню закрывается, повторное открытие выполняет обычный вход. Карта и подписи читаемы без обрезания.

Снимки: лист у ящика, карта RU, карта EN, после возврата.

QA APK обновлена, но её полный сценарий на устройстве в этом этапе не повторялся. OnePlus не подключён и для 0.10.0 не проверен. Личная приёмка владельцем новой карты пока не получена; длительный прогон и нагрев не измерены. На S23 оставлена карта RU, автоматические касания прекращены. На ПК открыт отдельный обычный двор: WASD/мышь, E у ящика слева от дома, затем I/Tab → «Карта»; существующий редактор не перезапускался.
