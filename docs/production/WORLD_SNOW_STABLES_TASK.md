# Конюшни снежного города — текущая ограниченная задача

Основание PDF141/plan_snow.py: Кн934/322, стены12×7м, вход к950/330. База актуальногоdev418d363, отдельная веткаcodex/snow-stables. Исполнитель Codex; Claude проверяет точный модуль и размещает на нижней террасе.

Файлы: build_snow_stables.py,s_stables.glb/.tscn,snow_stables.gd,validate_snow_stables.gd и эта карточка. Только отдельное строение, конюшенный проход/стойла/поддержанные кормушки/утеплённая кровля. Животные/NPC/езда/квестовые механики не добавляются этой задачей; их отсутствие не означает готовность живого города.

Каменный цоколь/тёмное дерево/сланцевая кровля S-H/S-S. Стойла не перекрывают вход и центральный проход; двери существующего village_door.gd, все опоры/пол/коллизии настоящие. Новое расположение города не вводится.

Проверки: физический обход прохода/входа каждого стойла и возврат, дверь с двух сторон, опора предметов/света; native фасад/кровля/интерьер и сравнение с каноническими S-H/S-S. Независимое ревью Claude точногоhead перед слиянием. Посадка/обычный герой/соседи/погода/ночь/актуальная APK/S23/FPS отдельно обязательны.

Состояние WIP, не подключено в кампанию. Все QA/BLEND/снимки толькоlocal/.

Собственная QA Codex:16 физических сегментов — вход/все4стойла/подходы к кормушкам/возврат, дверь снаружи/изнутри PASS. Guards занятости/открытых ворот, скрытие кормушек/фонаря, дальний/ближний свет/override PASS. Native фасад/интерьер/задняя стена и общий кадр с каноническими S-H/S-S осмотрены; наружные стойки/обвязка, два высоких задних продуха, ряды сланца по снежной опоре.
