## ПК

По прямой просьбе владельца игра запущена отдельным видимым окном **ASHBOUND (DEBUG)** из `C:/Users/prost/Documents/AshBound` через Godot 4.7.2, размер 1440×810. Существующий редактор уже открыт в том же проекте с несохранённой `test_world.tscn`; он не закрывался, его сцена не перезаписывалась.

Процесс нового окна отвечает; журнал содержит `ASHBOUND_COURTYARD_READY` без ошибок Godot. Рендерер: Vulkan 1.4.351 / Forward Mobile / RTX 4090 Laptop GPU. Это текущий запуск проекта для ручного теста, не повторная проверка экспортированного EXE. Журнал: `.tools/manual-pc-running.log`.

Управление: **WASD** — движение, **Shift** удерживать для бега, мышь — обзор, **E** — действие, **ЛКМ** — удар, **Esc** — переключить захват курсора. В редакторе **F5** запускает основную сцену первого двора; F6 запускает текущую открытую сцену и может открыть старый `test_world`.

Обе сессии оставлены владельцу для теста. Проверить чередование ходьбы/бега на одном участке во всех направлениях и при вращении камеры, особенно размер головы/корпуса и скачок при переключении. На Android режим выбирается кнопкой «Ходьба»/«Бег». Отзыв владельца записывается отдельно; сам запуск теста не является положительным отзывом.
