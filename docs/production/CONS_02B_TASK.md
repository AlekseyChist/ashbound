# CONS-02B — состояния и ввод обычного HUD

23 сентября 2026. Основание: текущая очередь CONS-02B после PR #59. База dev `344096eb33e574ee43b5b7039eacde7a0fba5797`, ветка `codex/cons-hud-input`.

Результат для игрока: движение, удар и бег на обычном HUD не запускаются отменённым/недоступным вводом и не остаются зажатыми после меню, паузы или потери фокуса. Проверить существующие состояния, исправлять только воспроизведённые расхождения. Исполнитель — Codex по D-047: владение касаниями, фокус и взаимодействие HUD с меню/игроком; основные тесты также Codex, отдельным проходом QA.

Разрешены `scripts/courtyard/courtyard_hud.gd`, при доказанной необходимости его сцена; новые проверки `scripts/tools/validate_hud_input.gd/.tscn`; средства сборки/запуска `tools/build-combat-ui-preview.mjs`, `tools/run-combat-ui-checks.mjs`; эта карточка, протокол, STATUS/MEMORY/ROADMAP/docs/README и материалы проверки. Изменения других игровых файлов требуют сначала уточнить карточку и записать причину в STATUS.

Сохраняем геометрию/палитру HUD, EN/RU, кнопки блока/уклонения, механику боя, кампанию и профиль сохранений, жест доступа к меню и переключение бега на нажатие. Не добавляем системы, противников, новые панели или художественное направление. Визуальная опора — STYLE_REFERENCE и CONS-02A; проверяем состояния в той же сцене и в движении.

Реальные интерфейсы: `CourtyardHUD._input(event)`, `reset_controls()`, сигналы `move_changed(Vector2)`, `attack_pressed()`, `interact_pressed()`, `run_changed(bool)`; поля `_touch_move_index/_touch_attack_index/_touch_run_index`; `Button.disabled/is_visible_in_tree()`. Меню вызывает reset, скрывает HUD и отключает его `_input` при `request_open()`, восстанавливает при `close_menu(bool)`. Проверка через `Viewport.push_input`, а не только прямые вызовы обработчиков.

Приёмка: отменённый DOWN не действует; отменённый UP освобождает своего владельца; одно касание не начинает второе действие; второй палец/эмуляция не отпускает первый; скрытая/disabled-кнопка не действует; фокус/пауза/меню сбрасывают движение и визуальное удержание, позднее отпускание не действует; после возврата свежий ввод работает. RU/EN и штатное движение/удар/бег/защита сохраняются.

Проверки: сначала воспроизвести на базе, затем Godot без графики и с графикой; существующие проверки UI, боя, движения и меню по затронутому поведению. Android QA на S23 и обычная актуальная APK, версия/хеш/журнал, проверка реального ввода и возврата из фона. OnePlus только при наличии, иначе ограничение. Изолированный стенд не считается кампанией. Для передачи владельцу — установленная APK и видимое окно ПК. Новые игровые тексты не планируются.

Git: проверенный diff → PR в dev → точный head/проверки/слияние GitHub → обновление dev и удаление ветки. Main и исходные пользовательские файлы сохраняются. Результат и следующая ограниченная задача — после проверки.

Выполнено: изменён только игровой `courtyard_hud.gd`, сцены/боевые скрипты не менялись. Дефекты и исправление собственной ошибки завершения сцены, проверки, версии/хеши и ограничения записаны в [протоколе](CONS_02B_CHECKS.md).
