# INVENTORY-TRANSFER-QA-01 — достоверная проверка языка переноса вещей

- Основание: в независимой QA ITEM-DATA-02 на исходном dev повторились три старых RU-ошибки `validate_inventory_transfer`. Разрешено расследование и исправление средства проверки, без изменения продукта ради зелёного теста.
- Исходник: dev `090139be4d8507ca9ed7a8ede1b57993dafb54b0`; ветка `codex/inventory-transfer-qa`. Исполнитель Codex: основные тесты и постановку проверки по D-047 пишет и проверяет сам.
- Результат: тест переносов действительно переключает EN → RU в чистом окружении и отличает ошибку подготовки языка от ошибки текста интерфейса.
- Границы: `scripts/tools/validate_inventory_transfer.gd`, эта карточка, краткий итог в STATUS. Игровой инвентарь, панель, переводы, баланс, сохранения и ассеты не менять. Если ошибка в продукте — отдельное решение по исполнителю/карточке; не ослаблять ожидаемые русские строки.
- Контракты: `Localization.load_preferences(path, device_locale)` читает настройки без записи; `set_language(preference) -> Error` сначала сохраняет ConfigFile и лишь после успеха меняет язык; `get_language() -> String`. Панель принимает `language_changed`, обновляет выбранный экземпляр и его местонахождение.
- Гипотеза: тест пишет в `res://.tools/`, которого может не быть в staging; результат `set_language` игнорируется. Проверить фактический код ошибки и язык, не считать это установленной причиной до воспроизведения.
- Проверки: Windows/Godot 4.7.2, только headless, отдельный APPDATA, последовательные процессы. Сначала исходный тест и диагностическая локальная копия в чистом staging; после исправления тот же полный тест 10 групп. Дополнительно намеренно недоступный путь должен давать понятный отказ подготовки, а тест после успешного запуска удаляет свой временный файл. Проверки существующей локализации запускаются по затронутому контракту.
- Визуальный вид/раскладка не меняются; образцы UI не пересматриваются. APK и личная художественная оценка для исправления теста не требуются; мобильная приёмка игровых PR остаётся отдельной.
- Все диагностики и логи — `local/qa/inventory-transfer-qa/`; основной checkout Claude, окно владельца и его настройки не затрагиваются.

## Результат

- Причина подтверждена на исходном dev: с существующей `.tools/` все 10 групп проходят; без неё три RU-ошибки. Диагностическая копия показала `set_language` → `ERR_FILE_NOT_FOUND` (7), язык остался `en`. Каталог оставлял другой тест; это зависимость от порядка проверок, не установленный дефект русского интерфейса.
- Исправление: уникальный временный файл в `user://`, отдельно от настроек игрока; проверка начального EN, результата сохранения RU и фактически применённого языка. Прежние требования к строкам, данным и переносу сохранены. Существующая очистка удаляет временный файл.
- Отдельный QA-проход Codex: полный transfer 10 групп пройден с `.tools/` и без неё; временных файлов не осталось. Инъекция недоступного пути в локальную копию даёт exit1 и явный отказ сохранения/применения языка. Локализация 8 групп и запись/чтение настройки в двух отдельных процессах проходят; журналы успешных прогонов без ошибок/предупреждений движка.
- Логи: `local/qa/inventory-transfer-qa/` worktree Codex. Тесты выполнены на Windows в отдельном APPDATA; APK не собиралась (изменены только тест и документы). Это собственный QA, не внешнее ревью.
- Новых файлов: 1, бинарных: 0. Игровые PR144/146/152/154 этим не принимаются; старые APK не устанавливались.
