# VILLAGE-GODOT-01 — прогулка по трём зданиям

24 сентября 2026, D-069. Владелец после просмотра H01 в Blender: «мне нравится го делать остальные и в годот». H01 принят как первая 3D-основа; «остальные» в текущем наборе — уже изготовленные W01 и B01. Перенос всех трёх разрешён этим поручением, новые типы домов или окончательная расстановка деревни не подразумеваются.

- База dev `59a5c5cce686bd99e7548b6e562743a555a4ff7e`, новая ветка `codex/village-house-walkthrough`. Чужие import-изменения основного checkout сохранены; работа в изолированном рабочем каталоге.
- Один результат для игрока: пройти снаружи внутрь H01/W01/B01 через открываемые двери в Godot без загрузки и вернуться наружу, на ПК и S23.
- Это ограниченное расширение INTERIOR-01A с одного дома до трёх моделей по прямому поручению. Демонстрационная расстановка для проверки моделей, не новая утверждённая планировка поселения. WORLD-START-01 и глобальная карта не меняются.
- Опоры: VILLAGE-MODEL-01 (принятый внешний вид H01, семейство W01/B01), существующий ресурс принятого героя `assets/characters/world-graybox-v1/traveler_frames.tres`, UI-книга 1.0 и общая `ashbound_ui.tres`. Героя/кадры/масштаб не менять.
- Исполнители: Qwen через локальную Ollama — небольшой каталог трёх моделей с точными данными; Codex — связанная реализация дверей/коллизий/камеры/ввода, сцены, экспорт и QA по D-047. Новая Blender-геометрия не требуется; переносим проверенные GLB без изменений.
- Разрешённые файлы: `assets/buildings/forest-village-v1/` (копии трёх GLB и import), `scripts/world/village_*.gd`, `scenes/world/village_walkthrough.tscn`, `scripts/tools/validate_village_walkthrough.*`, `tools/build-village-walkthrough.mjs`, `tools/run-village-walkthrough-checks.mjs`, `localization/en.po`, `localization/ru.po`, эта карточка/протокол, `MEMORY.md`, `docs/README.md`, `docs/production/STATUS.md`, `docs/design/INTERIORS_AND_ACCESS.md`, `art/previews/village-godot-v1/`. Временные задачи/сборки/журналы — `.tools/`.
- Реальные интерфейсы: PlayerScene `set_move_input`, `set_run_input`, `request_interaction`, `interact_requested`, `stop_input`, `input_enabled`; CameraScene `set_target`, `get_camera`, `snap_to_target`, `rotate_view`, `stop_look`, `set_mouse_capture`; HUD `move_changed/run_changed/interact_pressed/restart_pressed`, `set_prompt`, `reset_controls`, `set_objective`. Использовать существующие сцены, общие скрипты не переписывать. При необходимости камера наследует текущий скрипт для локальной обработки помещения.
- Двери: физические полотна/петли с отдельным состоянием каждого здания; обе стороны входа, близкая видимая цель, клавиша E или явная кнопка. Повторное нажатие во время движения не дёргает полотно. Перекрытый героем сектор запрещает/останавливает движение без проталкивания. Фокус/пауза очищают ввод. Закрытая дверь и стены препятствуют движению, открытый проём проходим. Крыша остаётся, камера не проходит через стены. Ступени проверяются реальной капсулой, при необходимости локальный согласованный подъём коллизии порога.
- Не входят: замки/ключи/взлом, кража/содержимое сундуков, NPC/сохранение адресов, лестничная механика, бой, миграция основной кампании. Сундуки и лестницы пока обстановка. Отдельный пакет `org.ashbound.villagepreview`, версия 0.22.0/code54; старая карта и сохранения не подменяются.
- QA Codex: импорт ресурсов/метаданных; все три входа туда/обратно настоящим актором; закрытые двери/стены, диапазон и прямая видимость взаимодействия, повторные нажатия, блокировка сектора, независимость дверей, возврат фокуса/паузы, движение/камера/адаптивный HUD RU/EN. Проверка изображения и движения в помещении/снаружи, импорт/основные граничные тесты; свежая установленная APK на S23 с проверкой версии и журналов. Нужная оценка владельца запрашивается только после установки/запуска.
- Git после успешного QA: точный head PR → dev → GitHub merge → обновить dev → удалить завершённую ветку. Main не менять.
