# VILLAGE-WIND-01 — читаемые порывы растительности

- **D-075, 24 сентября:** прямое поручение владельца — сильнее раскачивать растительность при сильном ветре. Шаг перед предложенным VILLAGE-MATERIAL-STUDY-01; планировка Б v1.1 и принятый D-074 свет сохраняются.
- **Результат:** по спокойной/ветреной погоде видно разницу движения крон, травы и папоротников, с закреплённым основанием.
- **База:** dev `d5bd800a8b9a293c1c72ca7e2138bf0517bf879d`, новая `codex/village-wind-gusts`.
- **Исполнитель:** Qwen, локальная изолированная формула vertex и настройка её материалов; Codex — постановка, инструменты и основные проверки, отдельный просмотр фактического diff.
- **Разрешённые файлы:** `assets/shaders/village_foliage.gdshader`, только `_setup_foliage()` в `scripts/world/village_atmosphere.gd`; Codex: `scripts/tools/validate_village_wind.*`, сборщик `tools/build-village-settlement.mjs`, только номер версии в заголовке окна/журнале в `scripts/world/village_settlement.gd`, протокол/артефакты `art/previews/village-wind-v1/`, эта карточка, STATUS/MEMORY/docs README и опора VILLAGE_LOOK_REFERENCE.
- **Контракт:** `effect_time` поступает из паузозависимых часов; `wind_strength` из пяти существующих профилей 0.15/0.45/0.95/0.16/1.0. `painted_weight=true` использует COLOR.a (высота кроны), иначе локальную высоту. Корни с весом 0 не смещаются. Масштаб экземпляров не умножает повторно мировую амплитуду. `foliage_batches` содержит только крону/подлесок; стволы и коллизии неизменны.
- **Границы:** без новой геометрии, UI, звука, повреждений от ветра; без изменения освещения/fragment, героя, профилей погоды, сохранений, EN/RU. Увеличить запас culling под фактическое максимальное смещение.
- **Опора:** `docs/art/STYLE_REFERENCE.md`, `docs/art/VILLAGE_LOOK_REFERENCE.md`, принятые дневные/штормовые виды `art/previews/village-atmosphere-v1/`; сравнение в той же деревне, а не новое художественное направление.
- **Критерии:** заметные плавные порывы в ветре/шторме, спокойное ясное состояние; более медленные деревья и более подвижный подлесок, без дрожания всего дерева. Нулевой ветер статичен; пауза не меняет фазу. Корни/стволы/дома/герой неподвижны относительно этой деформации. Нет исчезновения краёв крон, ошибок движка и существенной потери мобильной частоты кадров.
- **QA Codex:** рендер фактического шейдера при нулевом/слабом/сильном ветре, закреплённом весе и повторном времени; временная серия деревни/сравнение движения; регрессии времени, погоды, паузы, трёх дверей и проходов, маршруты clear/storm. Проверка accepted-traveler SHA. ПК и S23 — свежая 0.23.4/code60, установленные APK сверить по SHA, телефон открыть перед передачей. Технический PASS не означает личную художественную приёмку.
- **Ограничение Qwen:** один конкретный возврат при дефекте, затем сложную часть принимает Codex с записью причины/авторства.

Результаты, фактическое авторство, журналы, хеши и Git-цикл: [VILLAGE_WIND_01_CHECKS](VILLAGE_WIND_01_CHECKS.md) после проверки.
