# CONS-02A — освободить боевой кадр от панелей проверки

23 сентября 2026. Очередь: первый ограниченный шаг CONS-02 после PR #57 и CONS-V01. Основание — поручение владельца продолжать по новым правилам. База dev: `ef2ddfd0d226232298ccc01887d89e549264e0c0`; новая ветка `codex/cons-combat-ui`.

Результат для игрока: при входе в боевой двор противник виден над героем, а переключатели проверки доступны из одной сворачиваемой панели в общем стиле HUD.

Входит: свёрнутая по умолчанию панель техник/рюкзака/поворота/возврата, краткая контекстная подсказка и сохранение крупных боевых кнопок. Старые варианты стендов сохраняются. Не входят: баланс, противники, рисунки/материалы, переделка ввода боя, интеграция в кампанию, новые системы или загрузка модели.

Разрешённая игровая реализация Ollama: новый `scripts/tools/combat_tools_toolbar.gd`, фабрика в `scripts/tools/combat_dodge_sandbox.gd`, компактное представление и соединение сброса в `scripts/tools/combat_dodge_toolbar.gd`, новые ключи `localization/en.po`, `ru.po`, `messages.pot`. Codex: независимые `validate_combat_ui.gd/.tscn`, `tools/build-combat-ui-preview.mjs`, временные QA/снимки в `.tools/`, данный протокол, `CONS_02A_CHECKS.md`, краткие обновления STATUS/MEMORY/индекса/визуальной опоры. Не изменять существующие игровые базовые классы, сцены и ассеты вне этого списка.

Реальные интерфейсы: `fist_technique_sandbox._create_preview_toolbar() -> CanvasLayer`, `toolbar.setup(owner: Node) -> void`, `refresh() -> void`; `sandbox.set_technique(value: String) -> bool`, `set_backpack_enabled(enabled: bool) -> bool`, `is_backpack_enabled() -> bool`; `CameraRig.rotate_view(relative: Vector2)` и `mouse_sensitivity`; `InventoryMenu.get_menu_state()` (0 — закрыто); `combat_dodge_toolbar` наследует `corner_enemy_toolbar`/`fist_defense_toolbar`, включая `_request_reset() -> void`, `_gating_ok() -> bool`, `_clear_all_input() -> void`, `_update_hint() -> void`; `defense.snapshot()` и `is_block_window_open()`. Новый контракт: сигнал `reset_requested` панели соединяется с существующим `_request_reset`, без обхода очистки ввода.

Эталон: STYLE_REFERENCE и исходные стили `HUD._btn_attack`/`RootControl/TopLeftPanel`; конкретный исходный вид — `docs/art/cons-01/images/ui-ru-normal.jpg`, английский `ui-en-normal.jpg`, мобильный `s23-ready.png`. Цветовые роли, размер боевых кнопок, безопасная область, 3D/2D-вид сохраняются. EN/RU равноправны; только новые ключи, пользовательские сохранения и язык не сбрасывать.

Критерии: по умолчанию скрыты все тестовые действия кроме кнопки раскрытия; пять действий доступны в панели; раскрытие/сворачивание не вызывает удар/захват камеры/смену техники; скрытые области не перехватывают ввод. Один жест — одно действие; отпускание вне кнопки, отмена, второй палец, эмуляция мыши, меню и потеря фокуса не оставляют отложенную активацию. F1–F4/F6, ПКМ/G, Space и сенсорные боевые кнопки сохраняют поведение. Панель закрывается при меню/потере фокуса; длинные правила помещены внутрь, снаружи одна короткая строка по текущему состоянию.

Независимая проверка Codex: parse/import; действия/видимость/ENRU/единый стиль/геометрия; отмены и одновременный ввод; отсутствие скрытого перехвата; прицельные регрессии уклонения/защиты/фаз/эффектов. Сравнить кадр до/после на той же камере, осмотреть действие в движении. Windows и подключённый S23; OnePlus не считать проверенным. Основной игровой пакет не заменять.
