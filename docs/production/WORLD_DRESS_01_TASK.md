# WORLD-DRESS-01 — живой лес вместо болванки

## Концепт и решение владельца

- **Концепт стартового района v1** (27 сентября, D-097): участок 800×750 м вокруг Лесных дворов на настоящем рельефе. Схема строится локально: `local/previews/world-start-01/concept.py` → `start-region-concept-v1.html` (D-080: картинки не в Git). Показан владельцу вместе с [атласом мира](../design/WORLD_ATLAS.md); ответ: «звучит всё просто топ, погнали».
- Зоны (координаты карты `x / z`, м):
  1. **Выгоны и огороды** — открытое кольцо вокруг деревни: изгороди, стога, грядки.
  2. **Ельник у тропы** — уже есть (TRAIL-01).
  3. **Волчий лог** — котловина в треугольнике троп (≈170 / 1260, на 30–50 м ниже троп): сырой ельник, ручей, болотце, валежник; логово волков.
  4. **Старый бор** — вдоль тропы к пещере: самые большие ели, мох, валуны, поваленные стволы.
  5. **Скалы у пещеры** — каменный выход с зевом пещеры (115 / 1170), без интерьера (CAVE-01 позже).
  6. **Сосняк на гребне** — лесная петля от пещеры к развилке; **смотровая скала** на высшей точке (205 / 1110, 89 м).
  7. **Опушки тракта** — неровная стена леса с прогалами, указатель на развилке (420 / 1210).
  8. **Склон к низинам** — редкие деревья, кусты, высокая трава.
- Всё за пределами района — лес по биомам с дымкой; настоящий лес там появляется позже, по зонам.

## WORLD-DRESS-01A — карточка

- **Результат для игрока:** за деревней и тропой холмы мира покрыты ельником с полянами, дороги, реки и места свободны; лес уходит в дымку к краю прорисовки.
- **Основание:** D-097; поручение владельца 27 сентября «проработка мира дальше, пока заглушка».
- **Исходный коммит:** ветка `claude/world-atlas-01` поверх `claude/ui-clean-01` (PR #131 ещё не слит).
- **Исполнитель:** Claude (роль Codex по D-047): расстановка связана с рельефом, дорогами, настройкой дальности, физикой и сборкой — не простая изолированная правка. Геометрия ели — 40 строк кода (конус × 4 + ствол), без Blender-экспорта.
- **Входит:** `art/world/far-forest-v1/bake.py` — запекание позиций (биом по цвету карты, граница леса 280–330 м, склон 30–38°, массивы и поляны по шуму; свободны дороги +5 м, тропа к трактиру 50 м, реки +4 м, озеро, города 140 м, места, руины столицы 150 м, деревня +120 м); `assets/world/far-forest-v1/instances.bin` (7764 дерева, 155 КБ); `scripts/world/world_far_forest.gd` — чанки 125 м, MultiMesh с тенями, стволы-препятствия, дальность по настройке; `village_settings.gd` — группа `draw_distance_scaled`; сборка мира включает данные леса.
- **Не входит:** настоящие деревья и подлесок стартового района (01B–D), лес пустыни/снега, ветер для дальних елей, новые модели, море (WORLD-SEA-01).
- **EN/RU, сохранения:** не затрагиваются.
- **Проверка:** `validate_world_far_forest` — число деревьев и чанков, ни одного дерева на дороге/в реке/в городах, местах, руинах, у деревни, все на земле, ствол преграждает путь, дальность следует настройке «Дальность»; регрессии мира и деревни. Обход со снимками ПК — `local/qa/world-dress-01a/`. Телефон — позже, по решению владельца (FPS в лесу проверить на остывшем S23).
- **Дымка:** существующий туман погоды уже растворяет край дороги; отдельный туман по глубине не вводился, чтобы не менять принятые виды погоды (D-074–078). Вернуться, если на телефоне край прорисовки режет.
