# CONS-02A — компактные инструменты тренировки

23 сентября 2026. Версия **0.18.2-combat-ui**, Android code **42**. [Карточка и границы](CONS_02A_TASK.md). Игровые файлы и исправления выполнила установленная локальная `qwen3.8-24k:latest`; основные тесты, сборка и проверка — Codex.

Верх боевого кадра освобождён: по умолчанию видны одна кнопка «Тренировка» и короткая подсказка. Панель раскрывает прежние пять действий и полные инструкции; заимствует ресурсы оформления HUD. Контекст различает подготовку удара и реальное окно точного блока. Размеры и правила боевых кнопок, движения, противников и эффектов сохранены. На ПК остаются F1–F4, F6, ПКМ/G, пробел и WASD.

## Независимая проверка

| Проверка | Фактический результат |
| --- | --- |
| Новый UI | 12 групп Windows без графики, 12 с Vulkan Mobile, 12 в нативной APK на Samsung S23 / Android 16 — PASS |
| Регрессии Windows | Уклонение 10, фазы стражника 8, рисованные эффекты 8, обратная связь 9 групп — PASS без графики и с графикой |
| Ввод | Реальные события viewport: мышь/касания, отменённый DOWN/UP, выход за кнопку и возврат, второй палец, эмуляция, палец 0, фокус/пауза/меню, позднее отпускание, F-клавиши, сброс защиты и удержанное движение — PASS |
| Тексты и геометрия | 151 ключ EN/RU/POT, независимая фикстура; общий стиль HUD, крупные кнопки, панель в safe area, отсутствие пересечения с D-pad и боевыми кнопками — PASS |
| Экспорты | Godot import, Android QA/preview и Windows EXE — PASS; экспортированный EXE запускает актуальную сцену без ошибок |
| Обычная APK S23 | Установлена с сохранением данных; версия и SHA-256 сверены. Настоящие касания панели/рюкзака, движение, удар/удержание блока/уклонение, меню и Home/возврат в тот же процесс; ошибок движка/краша не обнаружено |
| Сохранность | Профиль основной кампании побайтно сохранён. 12 пользовательских файлов и резервные копии, три прежние сборки совпадают с контрольной точкой |

PASS требует полного числа групп, ожидаемого маркера, успешного завершения и отсутствия `SCRIPT ERROR`, ошибок движка, FAIL/INCOMPLETE/TIMEOUT. Само сообщение Ollama не учитывалось как приёмка. Найденные дефекты игрового ввода/компоновки возвращались локальной модели. Codex также исправил ошибки собственного QA: ожидание кадра UI после физических тиков, идентификатор мыши, восстановление оконного фокуса и запуск Android через экспортированный launcher. Это не исправления игровых механик.

## Изображение и ограничения

[Сопоставление ПК и новые снимки S23](../art/cons-02a/README.md). Codex просмотрел RU/EN и состояния раскрытой/свёрнутой панели; верх сцены освобождён, текст помещается, ресурсы рамок/фона совпадают с HUD. Раскрытая панель занимает часть мира, но не перекрывает кнопки движения/боя. В последовательности записи S23 проверены движение, переходы поз и сохранение расположения UI; [4 секунды обычной APK](../art/cons-02a/s23-ui-motion.mp4). Это не оценка производительности эффектов и не полный маршрут CONS-05.

Личная оценка владельцем новой версии **ещё не получена**. OnePlus в этом проходе не подключён. Основная кампания остаётся 0.15.2; боевой стенд по-прежнему отдельный. CONS целиком не закрыт. Следующий ограниченный шаг — CONS-02B: ревизия оставшихся состояний обычного HUD, без новых механик.
