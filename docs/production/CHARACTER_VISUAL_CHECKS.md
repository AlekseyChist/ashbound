# Проверка компонента внешности

20 сентября 2026. Ветка `codex/character-visual-component` от `dev` (`0cd0285`). Игровой код и проверочный сценарий написаны локальной `qwen3.8-24k:latest` через Ollama. Codex прочитал изменения и выполнил проверки в Godot 4.7.2.

## Объём

Ракурсы, кадры и масштаб выделены из контроллера движения в `CourtyardCharacterVisual`. Добавлена проверяемая замена полного совместимого набора кадров с сохранением фазы. Новые костюмы, редактор внешности, послойная экипировка и направления NPC в эту задачу не входят; VIS-01 / CHAR-01 целиком не завершены.

## Проверки Godot

| `validate_character_visual.gd` | PASS: атомарное отклонение плохого ресурса, фаза/пауза, масштаб, замена во время удара, одно событие попадания, поворот камеры, независимость экземпляров, стартовый набор без устаревших алиасов и автозапуск |

В журналах финальных запусков есть соответствующие `ASHBOUND_*_OK`, нет `ERROR`/`SCRIPT ERROR`. Один лишь код выхода импортёра не использовался как доказательство: ранние проверки выявили ошибки типизации и стартового `autoplay`, которые исправила Ollama до повторного запуска. Журналы находятся локально в `.tools/visual-*.log`; последние исправления модели — `.tools/ollama-godot/runs/2026-09-20T15-14-09-174Z/`.

## Сборки

- Windows: экспорт выполнен, отдельно запущен `AshBound.exe`, получены `ASHBOUND_COURTYARD_READY` и снимок работающей сцены. Ресурсы встроены в EXE, отдельного PCK нет.
- Android: экспорт и подпись выполнены. На OnePlus 13T (CPH2723, Android 16) успешно установлена версия `0.3.1-character-visual`, код 4, пакет `org.ashbound.courtyard`. После разблокировки владельцем подтверждён запуск и получен снимок игрового экрана: герой, жители, мобильное управление и завершённый учебный маршрут. В журнале процесса не обнаружены SCRIPT ERROR / FATAL EXCEPTION; физический многопальцевый ввод отдельным испытанием ещё не проверен.

Экспортёр сообщает о выборе Android Build Tools 30.0.3 при target SDK 36; APK подписан и установлен. Импорт открытой старой сцены сообщает о резервном пути для UID модели Paladin и неподдерживаемом объёмном тумане; новая сцена двора эти предупреждения в игровом запуске не выдаёт.

Samsung S23, физический многопальцевый ввод и длительный нагрев остаются непроверенными. Этот протокол не означает готовность всей Android-поддержки или завершение M3.
