# VILLAGE-GODOT-01 — три бесшовных здания в Godot

24 сентября 2026, D-069. [Карточка](VILLAGE_GODOT_01_TASK.md), снимки, видео и отчёты.

## Результат и границы

H01 — дом лесника, W01 — мастерская, B01 — амбар доступны в отдельной прогулочной сцене `scenes/world/village_walkthrough.tscn`. Настоящие проёмы, открываемые двери со звуком и выделением, неподвижные стены/мебель, непрерывный вход и выход. Дверь отказывается двигаться при занятом секторе; если герой вошёл в сектор после начала поворота, останавливается и продолжает после освобождения. Повторное нажатие не перезапускает поворот. Состояния трёх дверей независимы в одном запуске.

GLB побайтово совпадают с проверенными Blender-выходами VILLAGE-MODEL-01. Godot извлёк встроенные текстуры рядом с моделями; они сохранены вместе с import-настройками. Новых рисунков героя/масштаба/кадров нет: используется принятая опора D-059. Ступени H01/W01 получили непрерывную поверхность столкновения по их верхним кромкам, B01 использует собственную рампу. SpringArm сохраняет крышу и ограничивает камеру стенами/обстановкой. UI использует общую книгу 1.0, RU/EN, крупные кнопки; подсказка перенесена вниз на общий фон, чтобы не перекрывать героя.

Размещение трёх моделей рядом служит осмотру. Это не готовая деревня/кампания: нет NPC, замков, взлома, обыска сундуков, адресного сохранения, лазания по лестницам или работы очага. Материалы — прежняя базовая запечённая отделка; финальная роспись/обжитость ещё впереди. При повороте у стены маленького H01 камера заметно приближается, герой может частично выходить за нижнюю границу кадра; это не изменение масштаба спрайта. Удобство этого поведения требует личной оценки. Художественная приёмка игровой сцены владельцем ещё не получена; INTERIOR-01 и CONS в целом остаются открытыми.

Воспроизведение из корня проекта (в отдельном worktree указать `--baseline-root` на основной checkout с настроенными Godot/Android):

```powershell
node tools/build-village-walkthrough.mjs --stage-only
node tools/run-village-walkthrough-checks.mjs
node tools/build-village-walkthrough.mjs --validate
node tools/build-village-walkthrough.mjs
```

Сборщик меняет стартовую сцену/версию/пакет только в `.tools/export-staging/`; `project.godot` и общие export presets исходного проекта не меняются. Для S23 установить QA APK, открыть launcher activity, дождаться `VILLAGE_QA_COMPLETE failures=0 buildings=3`, забрать `files/village-qa/results.json` и снимки через `adb exec-out run-as org.ashbound.villagevalidation`. После QA установить обычную APK и проверить её версию/запуск. Launcher для этой версии Godot — `com.godot.game.GodotAppLauncher`, внутренний `GodotApp` не экспортирован для внешнего запуска.

Управление: WASD/стрелки экранного крестика, Shift/«Бег», мышь или движение пальца по свободной правой части экрана для обзора, E/«Открыть дверь»/«Закрыть дверь». «Другой дом» переключает H01 → W01 → B01; «На исходную» возвращает ко входу выбранного здания. Esc освобождает/захватывает мышь. Если дверь просит отойти, освободить пространство перед полотном и повторить действие.
