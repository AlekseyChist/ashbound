# BIOME-01B — первый внешний маршрут

23 сентября 2026, D-050. Исходный dev `963f639dc95bd49fbfec27a65829e6e56ca6bfb8` после PR #64. Ветка `codex/forest-route`.

Один результат: на ПК и телефоне можно пройти от лесной окраины по дороге с развилкой через мост к возвышению с видом на силуэт города и вернуться. Главная линия около 633 м, альтернативная лесная петля добавляет около 113 м. Это проба масштаба 600–800 м; расстояние считается по оси дороги, фактическое прохождение измеряется отдельно.

Это отдельная сцена и приложение «AshBound Forest Route», версия 0.19.0-forest-route/code45. Текущая кампания и боевой стенд сохраняются. Вход — запуск сцены/приложения, выход из эпизода — обратный путь или «На исходную». Переход из кампании и перенос боя сюда не входят в задачу. Нет новых квестов, NPC, погоды, карты без предмета, сохранений, смерти от воды или производства города. Уточнение способа запуска внутри разрешённого макета не меняет D-050.

Исполнители: Qwen через установленную локальную Ollama — один изолированный компонент статической 3D-геометрии (земля, дорога, мост, хвойные деревья/скалы и дальний силуэт). Codex — согласование существующих игрока/камеры/HUD, состояния запуска/сброса/фокуса, переводы, упаковка и основные проверки. Геометрия не управляет вводом/сохранениями. Blender не обязателен: для этого макета подходят простые Godot-меши и имеющиеся модели; художественная проба следует после оценки маршрута.

Разрешённые файлы: новые `scripts/world/forest_route_environment.gd`, `forest_route_layout.gd`, `forest_route.gd`, `scenes/world/forest_route.tscn`; новые проверки `scripts/tools/validate_forest_route.gd/.tscn`; `tools/build-forest-route.mjs`, `tools/run-forest-route-checks.mjs`; EN/RU и `localization/messages.pot`; документация задачи/проверки, WORLD_BIOMES, STATUS, ROADMAP, MEMORY, docs/README; свидетельства `docs/art/forest-route/`. Общие игрок, камера и HUD не переписываются. При выявленной необходимой правке общего компонента сначала явно записать причину и расширение здесь.

Реальные интерфейсы: `courtyard_player.tscn` → CharacterBody3D, `set_move_input(Vector2)`, `set_run_input(bool)`, `stop_input()`, `facing_direction`, `move_speed=4.2`, `run_speed=6.4`. `third_person_camera.tscn` → `set_target(Node3D)`, `snap_to_target()`, `reset_view()`, `get_camera()`, `stop_look()`, `set_mouse_capture(bool)`. HUD — `move_changed(Vector2)`, `run_changed(bool)`, `restart_pressed`, `attack_pressed`; общая Theme из UI-BOOK-02. Ненужные органы взаимодействия/инвентаря скрыты, новых неработающих кнопок нет. Новый локальный контракт геометрии: `build(main_path: PackedVector3Array, loop_path: PackedVector3Array) -> void`, без _process и доступа к игроку; координаты задаёт отдельная планировка. Мировой масштаб для испытания — 1 единица = 1 м.

Визуальная опора: STYLE_REFERENCE, общий тёмный лес/земля/камень, существующий цельный путешественник и 3D-здания. Геометрия макета не объявляется финальным лесным стилем. UI — шрифт и роли книги 1.0, EN/RU, safe area, обычный регистр. Камера остаётся перспективной за спиной, 2D-герой сохраняет ракурсы и походку.

Приёмка Codex: загрузка без ошибок; действительные коллизии всей главной линии и петли, непрерывное физическое прохождение в обе стороны, мост/уклоны/развилка, сброс и фокус без залипания; движение и бег имеют прежние скорости; RU/EN и отсутствие пересечений HUD. Измерить фактическую длину/время, не подменять прохождение телепортами. Снимки начала, леса, моста и вида; оценка в движении и отдельные показатели кадра с указанным устройством/режимом. ПК headless/графика, экспортированный EXE и установленная APK S23 с версией/SHA-256. OnePlus — только если подключён. Сохранность профиля кампании, root diff и старых сборок обязательна. Личная оценка владельца отдельно.

Git: фактический diff → проверки → PR в dev → точный head/проверки/слияние GitHub → ff dev → удаление законченной ветки. Main не меняется. Следующий шаг после этой задачи — оценить длину и ориентирование, затем художественная проба ограниченного участка; CONS остаётся открыт.
