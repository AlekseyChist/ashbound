# Сборка снежного города по утверждённым участкам

Основание: PDF141/D-118 и явный ACK Claude169. База dev1201616; данные41 участков dbce3a4 переносим без изменений. Codex владеет новым world_snow_city.gd/валидатором и этой карточкой; Claude — plan.json/export_snow.py, рельефом/террасами/улицами/маршами/подключением world.gd и выемкой библиотеки. Башня параллельно делается другим исполнителем в отдельном worktree.

Контракт: build(world:Node3D), узел уже ребёнок world_root; карта=local+1000; yawGodot=−deg_to_rad(yaw); высота поworld.world_ground(x,z). Не сдвигать участки и не масштабировать неверный модуль под пятно. Размещать только соответствующие назначению и точным стенам принятые сцены; отсутствующее соответствие выводить явно как незавершённое. Общие серые блоки не считать готовыми зданиями.

Файлы текущей задачи: world_snow_city.gd, validate_world_snow_city.gd, эта карточка, неизменённые data/export из dbce3a4. Игровой JSON прямо нужен сборщику; QA/снимки/измерения толькоlocal/. Сборщик возвращает get_doors()/nearest_usable_door()/clear_door_highlights() для обычного действия мира, без нового пути ввода и HUD. Управляет guards интерьера и существующими лампами; регистрация взаимодействия в world.gd остаётся Claude.

Приёмка: точные координаты/углы/пятна, реальные габариты с крышей/навесами относительно всех соседних участков/дорог/воды/склона, опирание и свободные подходы, работоспособные двери/нижний выход библиотеки. Ошибки рельефа отдавать Claude с замером, не маскировать сдвигом. Весь город/маршруты в обычной камере при дне/дожде/ночи и актуальная APK/S23/FPS обязательны. Частичное сопоставление сцен не закрывает город и цель.

Первый контракт: шесть точных модулей/35 явных незавершённых участков/семь дверей (включая нижнюю библиотечную) PASS в отдельной фикстуре с ненулевым смещением world_root. Проверены координаты/yaw/масштаб1, выбор доступной двери и общий override ламп. Фикстура не подтверждает реальный рельеф/опирание/коллизии со всей улицей/полный маршрут. Следующий этап — подключение Claude в world.gd и фактический осмотр/замеры всей городской расстановки; город не готов.
