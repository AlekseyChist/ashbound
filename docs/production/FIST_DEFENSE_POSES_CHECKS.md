# Цельные позы защиты и реакции

22 сентября 2026. Ветка `codex/fist-defense-poses` от `dev` `e141a9a` после PR #43. Отдельная проба **0.16.1-defense-poses**, основной двор остаётся 0.15.2. **В работе; проверки и передача ещё не завершены.**

## Ограниченный результат

Два новых состояния для двух техник: неподвижное прикрытие и короткая реакция на пропущенный удар. Новичок держит руки неумело и открывает корпус, обученный прикрывается компактно. Лицо, спина и правый бок нарисованы отдельно, левый зеркалируется в этом безоружном случае. С рюкзаком и без него — 24 цельных кадра, без накладного аксессуара в игре.

Окна, дальность, доступ к блоку и остальные правила [пробы 0.16.0](FIST_DEFENSE_PROBE_CHECKS.md) не меняются. Реакция использует существующие 0,2 с игровой симуляции. Атака сохраняет свою фазу и изображение. Во время движения используются прежние ходьба/бег: новые кадры относятся к защите стоя, отдельные шаги с поднятыми руками ещё не нарисованы. Успешный блок сохраняет защитную позу и прежнюю обратную связь механизма; отдельного кадра парирования пока нет.

Рисунки — встроенный ImageGen с прежним путешественником как образцом. Общая база новых поз заморожена; рисунок экипировки переносится через рабочие области маски с точным сохранением остальных пикселей. [Исходники, происхождение и задания](../../art/characters/fist-defense-v1/README.md). Сборку ресурсов и игровой код выполняет локальная Ollama, основные тесты — Codex.

## Повторение

```powershell
$env:ASHBOUND_QA_PYTHON = 'путь-к-python-с-Pillow-и-numpy'
node tools/run-defense-poses-pipeline.mjs
& $env:ASHBOUND_QA_PYTHON tools/validate_fist_defense_art.py
node tools/run-fist-defense-checks.mjs
node tools/build-defense-preview.mjs
node tools/build-defense-preview.mjs --validate
node tools/build-defense-preview.mjs --validate --ui
node tools/build-defense-preview.mjs --validate --poses
```

Сборка повторяется в изолированных копиях `.tools/export-staging/`, без переимпорта файлов владельца. Проба: `.tools/builds/defense-poses/AshBound-Defense-Poses.exe` и `.tools/builds/android/ashbound-defense-poses.apk`, Android code 33. Основные `project.godot`/`export_presets.cfg` остаются 0.15.2/code 31. Управление: F1/F2 — техника, F3 — рюкзак, F4 — ракурс, F5 — входящий удар, G — удерживать защиту, F6 — исходные позиции; на телефоне соответствующие крупные кнопки.
