# WALK-PHONE-07 — новая ходьба на телефоне

23 сентября 2026. Прямое поручение владельца: «запусти тест на телефоне».
Исходный dev: `758aaa695031688b8fd43de89fd9980f92a24fb4`, ветка `codex/walk-phone-preview`.

Результат: отдельное управляемое приложение на S23 с WALK-POSE-06 и выбранным нижним рядом MOTION-SCALE-05. Это личная проверка кандидата, а не окончательная художественная приёмка или перенос в кампанию.

Исполнитель — Codex: упаковка существующих ресурсов в изолированную экспортную копию и собственные проверки. Новый игровой код/анимация не пишутся; поручение Qwen не требуется.

Разрешённые файлы: `tools/build-forest-route.mjs`, новый модуль упаковки `tools/walk-phone-preview.mjs`, проверка `tools/qa/validate_walk_phone.*`, эта карточка/протокол, STATUS/MEMORY/README/ROADMAP. Игровые `assets/`, `scripts/`, `scenes/` и исходные рисунки не изменяются. Сборки, журналы, снимки — `.tools/`.

Опора: `art/characters/walk-consistency-v1/walk-atlas.png`, выбранные коэффициенты в `capture.gd`; исходные кадры бега `assets/characters/courtyard/painted-motion-v2/run.png` сохраняются. В экспортной копии меняются только ссылка атласа walk/walk_side и метаданные: side walk ×0.95, side run ×0.9, front/back run ÷0.9. Baseline 182 сохраняется. Без подгонки отдельных кадров.

Интерфейсы: существующая `scenes/world/forest_route.tscn`; `reset_route()`; `player.set_move_input(Vector2)`, `set_run_input(bool)`, `stop_input()`; визуальный компонент читает `pixel_size_<action>_<view>`, опору считает как baseline × pixel_size. Проверка использует реальную физику и воспроизведение клипов. Боевая система, UI 1.0, EN/RU, сохранения прежних приложений не затрагиваются. Новому приложению отдельные packageId и user-dir.

Приёмка Codex: ресурс кандидата действительно попал в сборку; 8 поз и обе половины шага проигрываются в обе стороны, выбранные масштабы всех ракурсов, скорость и переходы/сброс прежние; ПК без ошибок движка; на S23 установка, сверка version/code/SHA установленного APK, касания ходьбы/бега, атака, Home/resume, сброс и журналы. Самостоятельная оценка движения не заменяет ответ владельца. После открытия для владельца автоматические касания прекращаются. OnePlus не проверяется без подключения.
