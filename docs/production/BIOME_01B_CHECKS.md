# BIOME-01B — проверка внешнего маршрута

23 сентября 2026. Версия 0.19.0-forest-route, Android code45. Исходный dev `963f639`, [карточка](BIOME_01B_TASK.md), [сравнение и движение](../art/forest-route/README.md). Main не меняется.

Отдельный исследовательский маршрут: окраина → лесная развилка/петля → мост → подъём с видом на условный город. Игрок, камера и HUD взяты из существующих сцен; общие контроллеры не правились. Удар без цели сохранён как существующее действие. Здесь нет боевой встречи, квестов, инвентарного меню и перехода из кампании. Боевой стенд 0.18.4 и кампания 0.15.2 сохраняют свои приложения и профили. Новый пакет — `org.ashbound.forestroute`, QA — `org.ashbound.forestvalidation`.

Qwen создала статическую геометрию и получила один конкретный возврат. После второго результата Codex исправил оставшийся неверный API SphereMesh, стык берегов/моста, конечные границы, интерпретацию цветов вершин и размещение бюджета деревьев вдоль дороги; выполнил интеграцию и упаковку. Это не приписывается модели и не называется внешним независимым ревью. Ошибки QA Codex: фиксированные экранные координаты не учитывали размер окна; проверка safe area не учитывала её смещение на S23. Исправлены координаты проверки, требование попадания в безопасную область сохранено.

## Проверенный объём

Ось главной дороги — 633,44 м; петля — 192,37 м вместо участка 79,06 м, добавляет 113,31 м. Эти числа относятся только к макету. Точные площадь/география всего мира и четвёртый биом не утверждены.

8 групп QA: состав сцены/скорости; лучи по поверхности каждые 2 м; коллизии настила/перил и русло ниже воды; реальные события HUD/обзора, фокус, EN/RU и размеры; непрерывная ходьба по главной линии; бег обратно; петля в обе стороны с подходом/возвратом; сброс ввода/позиции. PASS требует всех восьми групп, успешного завершения и отсутствия ошибок движка/скриптов. Запуск и отдельный маркер сами по себе недостаточны.

ПК headless — PASS, с фиксированным шагом и ускоренным выполнением проверки: 633,02 м / 151,03 с симуляции шагом, 633,60 м / 99,12 с бегом обратно, 734,14 м / 115,52 с для подхода и петли в обе стороны. Реальная длительность headless составляет секунды; это не личная прогулка.

ПК Vulkan Mobile 1280×720 — PASS; непрерывный проход с отрисовкой занял 151,34 с, возврат 99,22 с, подход/петля в обе стороны 115,63 с. У этого запуска фиксированный timestep, поэтому его дельты кадров не используются для оценки GPU/FPS. Проверены кадры начала, дороги, развилки, моста, подъёма и вида. Снимки/журналы локально в `.tools/forest-route-checks/`.

До города: 633.09 м / 151.74 с реального времени; обратно бегом: 633.73 м / 99.17 с; подход и петля в обе стороны: 734.14 м / 115.59 с. Никаких переносов между точками этих трёх измеренных отрезков нет. Сбой ADB прервал сбор журнала на ПК; тест на телефоне продолжился. Полный журнал и JSON с результатом восстановлены из того же процесса, повторная установка для этой проверки не выдаётся за непрерывное прохождение.

Это интервал кадров процесса во время данного шестиминутного прогона, включая захваты/частичную видеозапись, не GPU-профилирование, длительный тепловой тест или гарантия для будущего мира с NPC. ## Воспроизведение и границы

- Сцена `res://scenes/world/forest_route.tscn`.
- Сборка: `node tools/build-forest-route.mjs --baseline-root ПУТЬ_ОСНОВНОЙ_КОПИИ`. Для QA добавить `--validate`, только подготовка/импорт — `--stage-only`.
- QA: `node tools/run-forest-route-checks.mjs --baseline-root ПУТЬ_ОСНОВНОЙ_КОПИИ`; `--render` для графики, `--validation-stage` для QA staging. `--realtime` убирает ускорение с фиксированным шагом.
- ПК: WASD, Shift — бег, мышь — обзор, Esc — отпустить/захватить курсор; кнопка «На исходную». Телефон: стрелки, «Бег», движение пальцем по свободной правой части экрана, «На исходную».

Материалы/хвоя/мост — макет, город — восемь повторно использованных зданий; ещё два стоят на окраине. Это не бесшовная кампания и не построенный регион с жизнью NPC. Новый лес проверяется отдельно от боевого маршрута CONS. Личная оценка владельца и OnePlus открыты; CONS не закрыт. Следующий ограниченный шаг — оценить длину/ориентирование на установленном телефоне, затем художественная проба участка, без производства всего мира.
