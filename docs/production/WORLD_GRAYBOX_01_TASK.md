# WORLD-GRAYBOX-01 — проходимый макет всего мира

23 сентября 2026, D-061: после предложения макета владелец ответил «ну че кого ждем» — начать реализацию. Это новое прямое поручение перед интеграцией героя/CONS; макет отдельный, производство финального контента не открывается.

- База dev `27852460d3d313d399ec02abcd1a557b4ecbe474`; ветка `codex/world-graybox`.
- Игровой результат: увидеть весь рабочий регион 2×2 км в 3D, пройти между четырьмя площадками городов через рельеф/дороги/переправы, переключать общий обзор и героя на ПК/S23.
- Основа: данные карты v0.3; 2×2 км/высоты/расположение остаются проверяемой гипотезой. Герой берётся из принятой опоры 0.19.4 без изменения рисунков/метаданных. Водные русла/отметки требуют согласованной поверхности; сам граф не доказывает проходимость.
- Qwen через Ollama: изолированный новый сборщик геометрии/коллизии `scripts/world/world_graybox_geometry.gd` с точным входом heights/colors/grid. Codex: ограничение высот дорог/воды/городов, интеграция ресурсов/камер/касания/режимы обзора, упаковка и собственный отдельный проход QA (D-047). Blender не нужен для этого параметрического макета; готовые текстуры/модели не создаются.
- Разрешены `art/world/graybox-v1/*`, `assets/world/graybox-v1/*`, `assets/characters/world-graybox-v1/*` (копия принятого ресурса/атласа), новые `scripts/world/world_graybox*.gd`, `scenes/world/world_graybox.tscn`, тесты `scripts/tools/validate_world_graybox.*`, `tools/build-world-graybox.mjs`, `tools/run-world-graybox-checks.*`; EN/RU/POT для нового тестового HUD; эти документы, STATUS/MEMORY/ROADMAP/docs README. Существующие персонаж/камера/боевые сцены/сохранения не переписывать.
- UI: книга 1.0, `assets/ui/ashbound_ui.tres`; action30/body30/caption22, бронзовая рамка/тёмная панель, крупные пальцевые кнопки. Обычный регистр EN/RU, новые строки через каталоги. Обзор/быстрый переход города — инструменты только этой тестовой сцены, не доступ к внутриигровой карте без предмета.
- Входит крупный непрерывный рельеф, видимые цветовые массы биомов, проходимые дороги/простые мосты/площадки городов и силуэты ориентиров. Не входят лесная детализация, текстуры, NPC/квесты, сезоны, новые механики боя/инвентаря, окончательная география и загрузка мира по секторам.
- Приёмка Codex: детерминированность высот, совпадение видимой поверхности и коллизии, все пять дорог в обе стороны реальным CharacterBody3D, мосты/подходы/стыки/рельеф, safe spawn, свободный обзор/возврат/касания/потеря фокуса, принятый герой/EN/RU. Просмотр общей формы и движения отдельно от чисел. APK install/version/code/base.apk SHA, журнал/касания S23, доступный ПК; OnePlus только при подключении.
- После QA открыть актуальный тест на телефоне и отдельное видимое ПК-окно; затем прекратить автоматические касания. Не прерывать начавшуюся ручную проверку. PR в dev, сверка точного head/проверок/конфликтов, GitHub merge, ff dev и удаление завершённой ветки. Main и 12 локальных файлов владельца сохраняются.

Промежуточная приёмка: Qwen создал два сборщика. После одного ограниченного возврата на каждый исправлены типизация нормалей и контракт ArrayMesh/лишняя высота полосы. Интеграционный тест Codex затем выявил неверный порядок обхода треугольников в исходном контракте координатора: raycast сверху не видел поверхность. Эту общую причину Codex исправил сам в обоих сборщиках; не приписывать исправление Qwen. Повторная проверка пола/швов/дорог обязательна.
