# WORLD-START-01 — стартовый лесной район

**Приостановлена владельцем 24 сентября:** сначала концепт и явное согласование вида/нюансов, затем план и реализация. Эта проба не принята, сохранена в WIP-ветке и не предназначена для слияния без отдельного решения. Мобильный прогон остановлен; обычная APK телефона прежняя.

24 сентября 2026. Один результат: пройти существующую лесную петлю между посёлком, пещерой и развилкой таверны среди простых объёмов домов и леса, оценив масштаб и просветы с земли.

- Основание: владелец попросил продолжить мир. Стартовый лесной район выбран координатором как ограниченный следующий шаг; это рабочая планировка, не утверждение окончательной географии. Продолжение перед интеграцией героя/CONS явно записано в STATUS. Предыдущий WORLD-GRAYBOX-03 завершён PR #80.
- База: `7de6c1e298212ef122e7d5c5e8b4c727cef0684e`, новая ветка `codex/starter-forest-graybox` от актуального `origin/dev`.
- Исполнители: Qwen `qwen3.8-24k:latest` через локальную Ollama создаёт изолированные простые объёмы домов/хвойных деревьев с коллизией. Codex согласует размещение с рельефом, дорогами, камерой и точками появления; пишет и запускает основные проверки. Это разделение по D-047, без облачной реализации.
- Входит: пять домов вокруг свободной площади; ограниченный лес вдоль существующей петли, просветы у мест и развилок; воспроизводимые данные и измерение маршрута. Один отдельный макет 2×2 км; дороги, высоты, водоёмы и прочие места сохраняются.
- Не входит: окончательные модели/текстуры, интерьеры, услуги таверны, NPC/бой/квесты/прогрессия, посадка всего мира, новые UI-стили, изменения героя/кампании/сохранений. Домовые объёмы пока закрыты; деревья не являются системой вырубки.
- Разрешённые файлы: `scripts/world/world_graybox.gd`, новый `scripts/world/world_graybox_starter.gd`, `scripts/tools/validate_world_graybox.gd`; `art/world/graybox-v1/{build_starter.py,starter-*.png,README.md}`, `assets/world/graybox-v1/starter-region.json`; `docs/design/world-exploration-v1/{starter-region.json,README.md}`, `docs/production/{STATUS,ROADMAP,WORLD_START_01_TASK,WORLD_START_01_CHECKS}.md`, `MEMORY.md`, `docs/README.md`; `tools/{build-world-graybox,run-world-graybox-checks}.mjs`, новый `tools/check-world-starter.py`.
- Точные опоры: `world_graybox_landmarks.gd` (простые стены/крыши, цвета `92938b/766a56/777970/252a29`), `forest_route_environment.gd` (CylinderMesh/MultiMesh), STYLE_REFERENCE. Геометрия временная без текстур; UI book 1.0 и принятые цельные рисунки героя 0.19.4 сохраняются.
- Контракты: координаты исходной карты `[x,z,h]`, Godot `[x-1000,h,z-1000]`; рельеф 401×401, шаг 5 м. Код размещения использует те же треугольники при выборке высоты. Точки деревьев не попадают в дорожный коридор/площади/воду; дома стоят на заглублённом основании и не перекрывают выходы. Коллизия новых объёмов — layer 1, mask 0, герой layer 2/mask 5. Геометрия не получает обработчики ввода/процесса.
- Приёмка Codex: детерминированный сборщик; сохранность географии/принятого героя; реальные стены/стволы останавливают героя, обход остаётся открыт; все 23 дороги в обе стороны; EN/RU, камера/фокус/модальный список мест. Проверить вид посёлка, лесного пути, пещеры и развилки в реальном рендере и движении.
- Версия отдельного макета: `0.21.3-starter-region`, Android code 53. Проверки ПК и свежей установленной APK на S23. На старте ADB не видит телефон; владелец подтвердил, что подключит его. Отсутствие устройства не заменяет мобильную проверку. Личная художественная оценка отдельно.
