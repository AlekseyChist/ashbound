# VILLAGE-ATMOSPHERE-01 — Gothic-атмосфера тестовой деревни

24 сентября 2026, D-072, база `529f7ac6abdcae7f1e2ad56c493b25f91c8a1b6d`, ветка `codex/village-atmosphere`. Сборка участка завершена PR #90; новая карточка продолжает прямое поручение владельца. Результат: пройти тот же участок при плавных сутках, дожде/ветре/тумане, увидеть насыщенный природный цвет, глубокие тени и тёмную ночь с тёплыми интерьерами. Сам вид ещё требует личной оценки владельцем.

Исполнитель Codex: взаимодействие времени/погоды, паузы/фокуса, материала героя, укрытий, шейдеров и экспорта — сложная интеграция D-047. Qwen через локальную Ollama: только изолированная таблица пяти погодных профилей по точным данным. Основные QA и визуальное сравнение Codex, отдельный проход собственного кода; это не внешнее ревью.

Разрешены `scripts/world/village_atmosphere.gd`, `village_weather_profiles.gd`, `village_rain.gd`, текущие `village_settlement.gd`, `village_dressing.gd`, `village_terrain.gd`; `assets/shaders/village_*.gdshader`; `tools/build-village-settlement.mjs`; новые `scripts/tools/validate_village_atmosphere.gd`/`.tscn`; дополнение экспортного списка/QA сцены; ключи `localization/{ru,en}.po`/`messages.pot`; протокол/снимки `art/previews/village-atmosphere-v1/**`, текущие MEMORY/STATUS/README/дизайн атмосферы/эта карточка. Принятые PNG, кадры, pixel_size/геометрия героя и общий character_depth shader не меняются. В runtime допускается единый `Body.modulate` света для всех поз, без покадровой нормализации.

Контракт: `configure(world: Node3D)` после `dressing.build`; время `hour` в [0,24), 60 секунд на игровой час, независимый плавный погодный переход. `set_hour`, `set_weather`, `advance` для контролируемой проверки; сохранение только отдельного состояния этой прогулки, без календаря кампании и без продвижения офлайн. При `world.is_input_available()==false` часы/эффекты заморожены, без накопления delta. Переключение времени вручную в тестовом режиме явно выбирает время, а не ускоряет календарь. Время/погода сохраняются в отдельный ConfigFile, не трогать настройки языка или существующие сохранения.

Дождь вокруг игрока: ограниченное число капель/брызг, отсечение по карте высот фактических коллизий земли, крыш трёх домов и колодца (226×176, шаг 1 м), вид наружу остаётся мокрым из интерьера. Wind только новая растительность с закреплённым основанием, никаких деформаций героя. Насыщенный коричневый грунт/тёмная зелень, холодные тени, умеренная цветокоррекция. Обычный Environment fog Mobile; без Forward+, SSAO, SSR, объёмного FogVolume. Огни переиспользуют InteriorFill, физика/коллизии домов прежние. Новые 3D-модели в этом шаге не производятся; плоскости частиц — служебная геометрия эффекта.

UI книга 1.0 прочитана и визуально открыта: Theme `assets/ui/ashbound_ui.tres`, action30, min240×120, gap12, margin24, обычный регистр, EN/RU. Два переключателя тестовых условий над площадкой управления, без произвольных шрифтов/цветов; они не становятся игровым HUD кампании. 0.23.1/code57, прежний пакет `org.ashbound.villagepreview` обновляется на S23.

QA: день/сумерки/ночь/туманное дождливое утро при одной камере, движение ветра/дождя и герой idle/walk/run/ракурсы; сутки/оборачивание/пауза/большой delta, независимость погоды и времени, плавность перехода, неверные сохранения/загрузка. Реальные двери/интерьеры под дождём во всех трёх домах, сухость под крышей, вид наружу, дождь не за землёй. Касания переключателей, EN/RU/границы экрана, Home/возврат, новые APK/EXE, сверка SHA и устойчивый маршрут с эффектами на ПК/S23. Логи ошибок и завершение всех сценариев обязательны; технический PASS не означает финальной художественной приёмки. TIME-01/DAY-01/WEATHER-01/SAVE-01 кампании и CONS не закрываются этим стендом.
