# INV-01A — первый доступ к носимым вещам

20 сентября 2026. Ветка `codex/inventory-pocket-menu` от `307bd6b` (`dev`, после PR #19). Версия `0.6.0-pocket-inventory`, Android код 10. ПК проверен; завершение сенсорной проверки S23 ожидает свободного устройства, слияние пока не выполнено.

## Объём

Первое окно вещей открывается клавишей **I / Tab** или кнопкой **Inventory / Вещи** на экране. Сначала герой обращается к карману стартовой одежды; содержимое появляется только после завершения рисованного жеста. Повторная команда, Escape, закрытие окна, Android Back, потеря фокуса или доступа к карману отменяют действие и освобождают управление.

Это ограниченный этап INV-01A: просмотр реальных предметов, количества, надетой экипировки и монет. Выбор English / Русский / языка устройства находится внутри окна. Открытие само по себе не сохраняет настройку языка, не выдаёт предметы и не меняет Inventory. Ошибка записи настройки возвращает фактический выбор и показывает сообщение об ошибке настроек; это не уведомление о состоянии здоровья.

Доступ представляет компонент `PocketAccess` стартовой одежды с постоянным идентификатором. При его удалении, замене или отключении меню закрывается. Сам компонент не хранит копии предметов. Размещение вещей между несколькими физическими ёмкостями, смена одежды/рюкзака, ограничение вместимости кармана и запись кампании на диск остаются следующими частями INV-01/SAVE-01. Не считать полный INV-01 завершённым.

В этом прототипе мир двора не ставится на паузу, а ввод героя, камеры и сенсорного HUD временно блокируется. Меню не даёт неуязвимость и не сбрасывает восстановление удара. Нанесение урона врагами во время меню ещё требует проверки вместе с будущей боевой системой. Применение, экипировка из окна, быстрые слоты, карта, здоровье, ранения и магия здесь не добавляются.

## Разделение компонентов и исполнителей

- `courtyard_character_visual.gd` и отдельный `PocketPose`: жест, камера, завершение анимации, восстановление обычного рисунка.
- `pocket_access.gd`: доступ к карману стартовой одежды.
- `courtyard_inventory_menu.gd`: состояния CLOSED → OPENING → OPEN, владение вводом, отмена и потеря доступа.
- `courtyard_inventory_panel.gd`: только чтение снимка Inventory, обновление по событиям, локализованные подписи, настройка языка.
- Редактируемые сцены Godot задают расположение окна; каталоги PO/POT содержат тексты EN/RU. Игровые идентификаторы от языка не зависят.

Весь игровой код, сцены и исправления написал локальный `qwen3.8-24k:latest` через Ollama. Codex подготовил задания, прочитал изменения и самостоятельно написал проверки. Рисунок создан ImageGen по существующему герою; [полный запрос, исходники и разметка](../../art/concepts/traveler-pocket-v1.md). Логи модели находятся в локальной `.tools/ollama-godot/runs/`, в Git не включаются.

Codex также ограничил размер чтения в мосте Ollama: запрос больше 200 строк возвращает ближайшие 200 строк вместо повторяющейся ошибки. Лимиты путей и прав записи не расширены. Это исправляет фактически наблюдавшийся цикл неверных запросов локальной модели.

При разработке проверки выявили неверную сериализацию анимационного ресурса, ошибочное определение завершения по остановке анимации, допуск зацикленного жеста, неверные обращения к API Godot и ошибки обработки касаний. Такие результаты возвращались Ollama для исправления. Выход 0 без ожидаемого маркера всех групп или при `SCRIPT ERROR`/ошибке движка не считается успешной проверкой.

## Воспроизведение

```text
node tools/validate-localization-catalogs.mjs
godot --headless --path . --script res://scripts/tools/validate_inventory_gesture.gd
godot --headless --path . --script res://scripts/tools/validate_inventory_panel.gd
godot --headless --path . --script res://scripts/tools/validate_inventory_menu.gd
godot --path . --script res://scripts/tools/capture_inventory_menu.gd -- --no-mouse-capture
```

Графическая проверка создаёт временные предметы только в отдельном QA-процессе и восстанавливает его исходный снимок. Эти фикстуры не запускаются из основной сцены и не входят в пользовательский маршрут.

Появившийся `settings.cfg` не удалён и не перезаписан. OnePlus не подключён, на нём новая версия не проверялась.

До слияния нужно закончить на свободном S23: открытие после жеста, закрытие, выбор EN/RU и его сохранение после перезапуска, Back, сворачивание/возврат и движение после закрытия. Полная пользовательская приёмка оформления и будущие рюкзаки/действия с вещами остаются отдельно. `main` не изменялась.
