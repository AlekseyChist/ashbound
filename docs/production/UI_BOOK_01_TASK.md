# UI-BOOK-01 — локальная книга интерфейса

23 сентября 2026. Прямое поручение владельца после BIOME-01A: устранить произвольные решения в регистре, шрифтах, размерах и оформлении UI через сохраняемый в проекте визуальный стандарт.

- Результат: автономная книга с образцами UI и точными параметрами, которую владелец и исполнители открывают из файлов репозитория без сервера.
- Исходник: `dev` `6fd36751578b4777e54a7044729b62ab5ecdcadc`; ветка `codex/ui-style-book`.
- Исполнитель: Codex — документация, аудит исходников и средства генерации справочника. Игровой код не меняется, Qwen для этого шага не требуется.
- Разрешённые файлы: `docs/art/ui/*`, `docs/production/UI_BOOK_01_TASK.md`, `docs/art/STYLE_REFERENCE.md`, `docs/production/STATUS.md`, `docs/production/ROADMAP.md`, `docs/README.md`, `MEMORY.md`, `AGENTS.md`.
- Входит: PDF-книга, автономная HTML-версия с локальным шрифтом, машинные параметры и читаемые правила, исходник генерации, точные опоры на действующий UI и список отличий от стандарта.
- Вне объёма: массовая переделка HUD/инвентаря, изменение ввода/боевых окон, новая APK, художественная смена направления. Подписи в установленной игре в этом документном шаге не меняются; отклонения не скрываем.
- Реальные интерфейсы: `courtyard_hud.gd::_apply_styles()` — 30 для кнопок, панель/рамка/состояния; `courtyard_hud.tscn` — действия минимум 240×120; `fist_defense_toolbar.gd::_cache_hud_attack_styles()` — наследование и отдельный сигнал окна; `DEFENSE_GUARD`/`DEFENSE_GUARD_NOW` в PO; `project.godot` — 1920×1080, canvas_items/expand. Дополнительно меню настроек, touch_inventory_panel, quick_bar и adaptive_screen_root.
- Визуальные опоры: STYLE_REFERENCE, реальные снимки CONS-02B. Новые образцы сохраняют угольную поверхность, бронзовую рамку и светлый текст; значения нормализации явно отделены от фактов текущего билда.
- EN/RU: в книге парные подписи; реальные PO и сохранения не меняются. Кириллица, цифры и символы проверяются в экспортированном PDF.
- Приёмка Codex: просмотреть все страницы, проверить текст/встраивание шрифта, самостоятельное открытие HTML без запросов к серверу, соответствие образцов параметрам, локальные ссылки/границы diff. Существующие файлы пользователя и сборки сохраняются.
- Платформы: проверяется справочник на ПК. Игровые ПК/Android и художественная приёмка владельцем этим не закрываются.
- Следующий шаг: применить принятый справочник к существующему HUD/защите отдельной ограниченной задачей с новой APK и проверкой телефона. Мир остаётся в обсуждении.

## Результат

- Созданы девять страниц PDF и автономного HTML, JSON параметров, локальный Open Sans SemiBold с OFL-1.1, README и воспроизводимый Python-генератор. Книга и правила связаны из AGENTS, MEMORY, STATUS, ROADMAP, индекса и STYLE_REFERENCE. Всего 18 файлов в разрешённых границах; локальный .gitattributes хранит PDF и шрифты как binary без преобразования строк.
- Шрифт получен из `ThemeDB.fallback_font` Godot 4.7.2, проверены имя, кириллица и латиница. Исходный WOFF2 сохранён; TTF — конверсия контейнера fontTools 4.65.0 без правок контуров. Лицензия получена из `Engine.get_license_info()`. Это средство извлечения справочного ресурса, не игровая реализация Qwen.
- Codex собрал PDF и отрендерил все девять страниц Poppler; просмотрел каждую. Исправлены невидимая галочка выбранного режима и правое поле схемы контейнера, повторно просмотрены затронутые страницы. Нет обрезаний, наложений и отсутствующих символов; выбранный режим показан на «Бег», чтобы не создавать образец переключаемого блока.
- PASS: границы 162 текстовых блоков; 9 страниц PDF; встроенный Open Sans; покрытие символов; 263 локальные ссылки; 49 уникальных ID решений; точные существующие PO-ключи; diff только по разрешённым файлам; `git diff --check`.
- HTML: статически проверены девять разделов/якорей, встроенный WOFF2 и снимок, отсутствие внешних ресурсов, скриптов и сетевых запросов. **Визуальный просмотр HTML в браузере не выполнен:** браузерный инструмент заблокировал локальный `file://` политикой URL. Обход не выполнялся. Основной просмотренный результат — PDF; HTML остаётся альтернативной локальной версией из того же источника.
- PDF SHA-256: `539fadb5ed71cf781498b8978df8020d4b453c20960dfc9e2edced7133775378`. Рендеры проверки локально: `.tools/ui-book/render/`.
- Игровые исходники, PO, тема и APK не изменены; ПК/Android в этой задаче не перепроверялись. В установленной 0.18.3 остаётся «БЛОК». Нового личного художественного отзыва владельца на книгу ещё нет. UI-BOOK-02 — отдельное применение к HUD/защите с текущей APK и телефоном.
- Пользовательские шесть `.import`, вложения и копии сохранены; исходная проверка `check-day-close.mjs` пройдена. Git-цикл — тематический PR в dev; проверенный head и результат слияния фиксируются в GitHub и итоговом сообщении. main сохраняется.
