Исполнители: Qwen через установленную Ollama — изолированный каталог проверенных материалов с точными путями/параметрами. H01 использует Forest_oak/plaster/roof/stone/cloth/iron. Новая отделка выбирает H01 и материалы по имени/роли, не меняет исходный GLB, геометрию, Transform или физику. Мебель/ткань/металл сохраняют старые материалы. Стены внутри и снаружи могут разделять surface: не наносить наружный мох/потёки внутрь. Скачанные оригиналы сохраняются с точным источником/лицензией/SHA. EN/RU/UI и сохранения не затрагиваются; UI Book 1.0 остаётся.
