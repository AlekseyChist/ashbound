# VILLAGE-SURFACES-01 / FREE-ASSETS-01

24 сентября 2026. D-073: владелец дал разрешение искать бесплатные ассеты в интернете, подготовить выборку с обсуждением и продолжать улучшение сцены; явно подходящие можно использовать и отчитаться после. Это не принятие каждого набора целиком и не смена художественного направления.

База `b7022d28c5a1e84f80fbab42d10919b563979203`, ветка `codex/village-surface-assets`. Один игровой результат: существующие тропы и поляны выглядят как земля и растительность, сохраняя насыщенную Gothic-палитру, читаемые дороги, свет/сырость/погоду. Сопутствующий результат — локальная выборка внешних бесплатных источников с точной бесплатной частью, лицензией, пригодностью и затратами адаптации.

Исполнители: Codex — исследование источников, интеграция мирового UV/масок/нормалей/освещения и экспорта, отдельный проход собственного QA. Qwen через Ollama — изолированный каталог, который привязывает шесть проверенных текстур к ShaderMaterial; точные интерфейсы и ресурсы в поручении. Скилл ollama-task-briefs. Новую геометрию Blender этот шаг не создаёт.

Разрешены: `assets/environment/village-surfaces-v1/**`, `assets/shaders/village_ground.gdshader`, `scripts/world/village_terrain.gd`, новый `scripts/world/village_surface_catalog.gd`, версия в `village_settlement.gd`, `tools/build-village-settlement.mjs`, новый `scripts/tools/validate_village_surfaces.gd/.tscn`, использование прежнего атмосферного QA через наследование и параметры его версии/папки отчёта; отчёты/скриншоты `art/previews/village-surfaces-v1/**`, выборка `docs/art/free-assets-v1/**`, README/MEMORY/STATUS/ROADMAP и эта карточка/протокол. Никаких изменений источников героя, домов, дерева, погоды, сохранений кампании, UI и планировки.

Контракт: цвет вершин terrain сохраняет прежний RGB; alpha хранит вес дороги [0,1] только для смешивания материала (не прозрачность). Мировые UV в метрах, нормали в базисе X/Z без зависимости от камеры; полноцветные карты с source_color, normal/roughness без гаммы. 1K текстуры, mipmaps, фильтрация; дождь темнит/снижает roughness прежним параметром wetness. Старый вид доступен только как QA-переключатель material detail_enabled. Исходные изображения скачиваются без изменения байт с источником/автором/CC0/SHA.

Приёмка Codex: лицензии по официальным страницам, SHA/размеры/отсутствие исполнения кода из архивов; реальный diff. Компиляция, отдельные проверки границ маски и импортированных карт, старый/новый вид с одной камеры днём и под дождём, обзор при движении, существующие маршруты трёх домов/двери, ночь/туман/фон, экспортированные ПК/S23 и SHA установленной обычной APK. Производительность сравнивается на прежнем маршруте. Технический PASS не означает художественного принятия владельцем.
