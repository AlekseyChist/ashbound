# FOREST-CITY-02 — дополнения Лесного города по книге мира

- **Основание:** D-118 (владелец принял книгу WORLD-PLAN-01 целиком), лист «Лесной город — построенное и дополнения». Продолжение FOREST-CITY-01 / PR #146 (схема D-119).
- **Результат для игрока:** у Лесного города есть места, которых требует сага:
  - Счётная изба Гизберта (дом 7 у северо-восточных ворот, с интерьером);
  - навесы-лотки рынка у колодца;
  - брод с вешками и двумя створными столбами ниже моста;
  - пристань ниже мельницы;
  - кожевня ниже по течению;
  - ристалище с чучелами за юго-восточными воротами;
  - нижний посад с избой Ветлы.
- **Исполнитель:** Claude (сборка мира и Лесной город по распределению D-118: Claude — сборка и семейства F/L/N/R, Codex — S/D и приёмка всего 3D). Художественная приёмка — Codex по маршруту в игре.
- **Файлы:** `assets/world/forest-city-v1/plan.json` (дополнения и блок `additions`), `scripts/world/world_forest_city.gd` (`_additions`, `counting_house`, новые виды зданий), `art/world/forest-city-v1/schema.py` (сохраняет дополнения при перезапуске), `art/world/far-forest-v1/bake.py` и `assets/world/far-forest-v1/instances.bin` (поляны у кожевни, посада и избы Ветлы), `localization/*.po*` (ключ `WORLD_FOREST_CITY_COUNTING_HOUSE`).
- **Границы:** только существующий лесной набор и реквизит деревни (H01/W01, тележка-лоток, чучело). Новые облики — книга с документами в Счётной избе, ограда ристалища, лагерь беженцев — только по концепту Codex. Жители и квесты не подключаются.
- **Проверки:** `world_village` 69/69, `forest_inn` 71/71, `world_far_forest` 11/11. `FOREST_CITY_ADDITIONS 12`, домов 32. Кадры из игры: `local/qa/forest-city-02/` (D-080).
- **Открыто:**
  - визуальная приёмка Codex всего маршрута — ворота, развилка, рынок, брод, пристань, посад, кожевня;
  - ПК и S23, FPS у города;
  - Счётную избу расстановка сдвинула на 17 м от точки плана (дорога) — проверить, что она по-прежнему читается «у развилки».
