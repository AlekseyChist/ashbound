# Книга интерфейса AshBound

Версия 1.0, 23 сентября 2026. Локальная опора UI-BOOK-01 по поручению владельца D-049.

- **[Открыть PDF-книгу](AshBound-UI-Book.pdf)** — визуальные образцы, размеры, кнопки и состояния.
- **[Открыть автономную книгу](index.html)** — тот же материал; файл открывается двойным щелчком, сервер и сеть не нужны. Шрифт и иллюстрация встроены.
- **[Параметры](tokens.json)** — единые имена ролей и значения для поручений исполнителям.
- [Исходник сборки](build.py), [шрифт и происхождение](fonts/README.md), [лицензия](fonts/OFL.txt).

## Обязательные правила

1. Перед любым изменением UI читать эту страницу и `tokens.json`, открыть соответствующий образец книги. В карточку задачи передавать точные роли и исходники, а не «сделать красиво».
2. Названия действий — **«Блок», «Удар», «Бег» / “Block”, “Attack”, “Run”**: первая буква прописная. Не использовать верхний регистр целиком или восклицания для выделения кнопки. Исключения — настоящие сокращения/клавиши: ПКМ/RMB, ЛКМ/LMB, WASD, 1–0. Динамическая подсказка в тексте может описывать срочность словами; подпись действия остаётся стабильной.
3. Шрифт — текущий **Open Sans SemiBold**, проверенный через `ThemeDB.fallback_font` установленного Godot. Семейство содержит кириллицу и латиницу. Не добавлять новый шрифт, искусственный bold, изменение регистра или индивидуальный размер кнопки без записанной причины и нового образца.
4. Размеры — логические единицы при базовом viewport 1920×1080, не физические пиксели телефона и не dp. Таблица ролей в JSON: заголовок страницы 44, раздела 32, действие/основной текст 30, вторичный 28, номер слота 24, пояснение 22. Меньше 22 для видимого текста не вводить. Длинный текст переносить, расширять контейнер или редактировать обе локали; не уменьшать шрифт отдельной кнопки ради влезания.
5. Базовая кнопка действия: минимум 240×120, радиус 8, рамка 1, внутренние поля 12×8, промежуток 12. Это минимум, а не обязательный фиксированный прямоугольник; фактическая ширина должна вместить обе локали. Внешний отступ 24 отсчитывается от безопасной области. Инвентарь/быстрые слоты имеют собственную плотность и требуют отдельного образца при переносе.
6. Состояния сохраняют шрифт, подпись и размеры. Нажатие/удержание и выбранный режим используют pressed; выбранный режим дополнительно обозначается меткой. Фокус заметен отдельным контуром, недоступность — тоном текста и отсутствием действия. Сигнал идеального блока меняет только цвет/контур кнопки на время реального окна.
7. Сохранять текущую угольную поверхность, бронзовую рамку и светлый текст. В JSON RGB/alpha — исходные значения Godot; HEX — округлённое представление для книги. Новый оттенок получает роль, основание и сравнение, а не случайный `Color(...)`.
8. UI не добавляет полос здоровья/маны, не перекрывает центр боя и не выдаёт ёмкость инвентаря/карту без предмета. Текущие правила состояния героя сохраняются.

## Как применять без произвольных исключений

Правка UI должна указывать версию книги, роли параметров, изменяемые состояния и EN/RU-примеры. Qwen получает нужные страницы и текущий исходник по правилам D-047. Codex читает diff, проверяет обычное/нажатое/недоступное состояние, длинные подписи обеих локалей, safe area и ПК/актуальную APK. Отклонение сначала описывается в карточке и примере книги; существенное изменение направления обсуждается с владельцем. Отдельного повторного разрешения для обычного применения стандарта не нужно.

## Что уже есть и что ещё переносить

Это **справочник, а не подключённая общая Theme Godot**. `.gdignore` исключает документы/шрифты книги из игрового импорта. Изменения `tokens.json` сами по себе не меняют APK. Перед подключением ресурс шрифта/темы нужно перенести в каталог игровых ресурсов отдельной задачей с лицензией.

| Слой | Факт в 0.18.3 | Направление применения |
| --- | --- | --- |
| HUD | Источник базовой палитры, 30 у действий, 240×120 минимум | Сохранить роли через будущую общую тему |
| Защита | Наследует стиль удара; подписи БЛОК/BLOCK и БЛОК!/BLOCK!; фактический rect 300×110 при минимуме 250×110 | Перевести регистр, убрать смену подписи в окне, согласовать высоту и проверить расположение на телефоне |
| Настройки | Заголовок 44, отдельная кнопка выбора 38; собственные фон/рамка/текст | Переносить по ролям и сравнить читаемость; 38 не добавлять в общий набор автоматически |
| Инвентарь/быстрые слоты | Собственная тёплая палитра, некоторые недоступные состояния через modulate | Отдельная задача миграции; геометрию сетки и drag-and-drop не менять попутно |
| Disabled / focus | Общего явного оформления во всех экранах нет | Образцы книги — нормализация для следующей реализации; её проверка ещё впереди |

Документ фиксирует требование единообразия и рабочую основу. Новые образцы не объявляют личную художественную приёмку владельцем. В установленной 0.18.3 подпись всё ещё «БЛОК»; новая сборка в UI-BOOK-01 не выпускалась.

## Воспроизведение

Из корня репозитория: `python docs/art/ui/build.py`. Нужен Python с `reportlab`; все шрифты/исходные иллюстрации локальны. Скрипт читает JSON, собирает PDF и автономный HTML и проверяет границы текста. PDF дополнительно рендерится и просматривается Codex, поскольку отсутствие исключений сборки не гарантирует хороший макет.
