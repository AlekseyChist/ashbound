## Воспроизведение

Инструмент запускается из корня рабочей копии. `--baseline-root` указывает на локальный AshBound с Godot, контрольной копией импортов и архивом проверки 0.18.1; эти машинные материалы не хранятся в Git. При их отсутствии просмотр готовой страницы работает, но точное повторение архива потребует указанных исходных файлов. Godot можно задать переменной `ASHBOUND_GODOT`, кэш — параметром `--cache`. Node 24; FFmpeg 7.1 для MP4.

```powershell
node tools/capture-cons-baseline.mjs --baseline-root C:/Users/prost/Documents/AshBound
node tools/capture-cons-baseline.mjs --baseline-root C:/Users/prost/Documents/AshBound --skip-import --motion
ffmpeg -y -loglevel error -framerate 60 -i .tools/cons-stage/.tools/cons-captures/motion-%04d.jpg -c:v libx264 -crf 20 -pix_fmt yuv420p -movflags +faststart docs/art/cons-01/combat-motion.mp4
node tools/build-cons-board.mjs --baseline-root C:/Users/prost/Documents/AshBound
```

В этой сессии FFmpeg предоставлен пакетом `imageio-ffmpeg==0.6.0` в локальной `.tools/qa-media-runtime/`; это инструмент упаковки QA, не зависимость игры. Исходные 1200 JPEG остаются в `.tools/cons-stage/.tools/cons-captures/`; поле `file` в [motion-events.json](motion-events.json) ссылается на этот временный набор. В Git сохранены видео и исходы десяти отрезков.

Захват использует отдельный профиль `AshBound_CONS_QA`. Игровая база и пользовательские импорты сверяются по SHA-256 с сохранённой сборкой. Постановочные позы отделены от настоящего расчёта контакта. Камера в инструменте QA отделена от SpringArm, чтобы нативное обновление плеча не сдвигало боковой осмотр; положение объекта в кадре проверяется автоматически.

[manifest.json](manifest.json) содержит версию, базовый коммит, сцену, платформу, параметры и SHA-256 каждого изображения, видео и инструмента захвата. [Журнал кадров](evidence/stills.log), [движения](evidence/motion.log), [проверки скрипта](evidence/parse.log). Наличие этих материалов не означает приёмку внешнего вида владельцем или перенос стенда в кампанию.
