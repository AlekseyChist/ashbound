Это запись установленной игры, не анимация HTML. Небольшое повторение кадров в контактных листах возможно из-за выборки видео в 15 fps; фактический порядок всех восьми фаз отдельно проверен игровым QA.

## Источник и производство

Ходьба берёт восемь целых рисунков `a0,e0,a3,f,d,e2,b,e3` из [SPRITE-GAIT-LAB-01](../sprite-gait-lab/README.md). Владельцу понравились её статичные кадры. Новый бег нарисован одним листом imagegen по прежнему `source-idle.png`; [точное задание](run-prompt.txt), [неизменённый исходный RGBA](run-source.png). Генерация: 23 сентября 2026, локальный результат `exec-9ff11159-c0be-4c0d-93a7-f7ae6d9767c4.png`. Выданные номера фаз не считаются доказательством анатомии: после просмотра порядок исходных ячеек изменён на `0,1,6,7,4,5,2,3`.

`pins.json` закрепляет хеши исходников. `build.py` только вырезает целые ячейки, равномерно масштабирует весь клип и сдвигает полный рисунок на общую опору. Конечности не вращаются и не растягиваются; промежуточный морфинг отсутствует. Полёт бега сохраняет подъём обеих стоп, а не прижимает каждый рисунок к земле. `manifest.json` фиксирует координаты и масштаб.

Атласы RGBA 1536×768, восемь ячеек 384×384. Один общий масштаб ходьбы 0,53; бега 0,53/0,9 компенсирует существующий коэффициент runtime. Метаданные SpriteFrames сохранены для совместимости старой экипировки; новые рисунки рюкзака не производились. Общая скорость игры и частоты поз не изменялись.

## Повторение

Из корня проекта: `python art/characters/painted-motion-v2/check.py`. После импорта PNG запустить Godot с `--headless --path ПРОЕКТ --script res://scripts/tools/build_painted_motion_frames.gd`; сборщик меняет только `walk`, `walk_side`, `run_side` bare-ресурса. Негативные проверки: `python art/characters/painted-motion-v2/check_builder.py ИЗОЛИРОВАННЫЙ_ПРОЕКТ GODOT_EXE`.

Codex оценил полные позы, смену ног и последовательные кадры телефонной записи. Прежнего постоянного приседа нет; остаётся небольшая разница разворота плеч/деталей между целыми рисунками. Это текущий проверяемый вариант, не личная приёмка владельца. Связь шага с расстоянием и точная фиксация стоп на земле пока отсутствуют.
