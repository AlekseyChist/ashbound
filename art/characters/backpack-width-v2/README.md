# Согласование тела в парных кадрах — 0.15.2

22 сентября 2026 владелец разрешил точную программную правку PNG после того, как повторная генерация продолжала менять пропорции тела. Codex подготовил рисунки и проверку; игровой сборщик ресурсов исправила локальная Ollama.

`compose.py` сводит **84 полных кадра** в семь атласов `assets/characters/courtyard/painted-backpack/*-v2.png`. Голова и нижняя часть тела берутся из исходного путешественника. Изображение рюкзака, ремни, контактные тени и складки взяты из соответствующей нарисованной позы, выровнены по голове и ограничены областью экипировки. Передние руки и рукава сохраняют перекрытие. Для каждой позы получается готовый цельный PNG; игровых слоёв аксессуара нет. Новые 12 фаз удара новичка из 0.15.0 не перерисовывались; исправленные общие позы и обученная техника пересобраны в обоих наборах пробы.

Исходные PNG без рюкзака и прежние листы рюкзака сохранены. Арт-исходники `donors/` — неизменённые ответы встроенного ImageGen:

| Лист | Ответ генератора |
| --- | --- |
| side.png | exec-caf30f14-04a8-463a-ba40-d321fe905238.png |
| back.png | exec-666ffb2b-3394-4f91-8c6e-ec2a5287a206.png |
| front.png | exec-5c2e08e5-a4c0-4f80-b791-02a57cd5c1c8.png |

Листы бега и кармана используют существующие соответствующие `painted-backpack/*-pack.png`. Новая обработка меняет только производные `*-v2.png`. Прямоугольники выпущенных поз считываются из базовых SpriteFrames; соседние кадры и неиспользованные контрольные ряды не добавляются в результат.

Повторение: Python с Pillow и numpy, `python art/characters/backpack-width-v2/compose.py`. Маски, таблица совмещения и шесть листов сравнения сохраняются в `.tools/`. Затем Godot запускает `scripts/tools/build_painted_backpack_frames.gd` и `scripts/tools/build_fist_preview_frames.gd`. Эти GDScript-сборщики написаны Ollama; Codex не заменял их собственной игровой реализацией.

Независимые проверки: `tools/validate_backpack_art.py` сравнивает защищённые пиксели напрямую с исходниками, `scripts/tools/validate_painted_frames.gd` измеряет тело в одинаковых координатах виртуального полотна, проверяет фазы, опору и размеры. Полный результат выпуска — [протокол](../../../docs/production/BACKPACK_PROPORTIONS_CHECKS.md).
