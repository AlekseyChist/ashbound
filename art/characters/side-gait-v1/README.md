# Боковой шаг путешественника — производственная база v1

SIDE-GAIT-02. Создана по явному разрешению владельца на точную программную сборку из исходного рисунка. [Общий стандарт](../../../docs/art/ANIMATION_PIPELINE.md), [карточка](../../../docs/production/SIDE_GAIT_02_TASK.md).

Автономный просмотр: нормальный/замедленный темп, пауза, следующий кадр и разворот; открывается из файлов без сервера. [Сравнение исходника и сцен, запись S23](../../../docs/art/side-gait-02/README.md), [фактическая проверка](../../../docs/production/SIDE_GAIT_02_CHECKS.md).

## Источники и данные

- `rig.json`: четыре исходных PNG с SHA-256, маски тела/руки/бедра/голени/стопы, суставы, защищённое лицо/волосы, участки восстановления жилета и восемь фаз walk/run. Исходники — прежние traveler-v1 / traveler-run-side-v3 и их согласованные варианты рюкзака v2.
- `build.py`: Codex, разрешённая художественная сборка Pillow/numpy. Двухзвенная нога с постоянными длинами, сдвиг дальней ноги на четыре кадра, противофаза рук, фиксированная опора по фактической подошве, premultiplied alpha. Рабочие части сводятся до игры; runtime-рига/накладного рюкзака нет.
- `check.py`: отдельный проход QA Codex по исходникам, чередованию контактов/рук, опоре/полёту, защите головы/ног в паре, воспроизводимости и четырём отказам без повреждения экспорта. `check_resources.py` сверяет все 30 клипов и метаданные с коммитом до задачи.
- `manifest.json`: входы и хеши финальных атласов. Игровые PNG находятся в `assets/characters/courtyard/side-gait-v1/`.
- `PROBES.md`: отклонённые генеративные пробы и их задания. `draw_pose_guide.py`/`run-pose-guide.png` — вспомогательная анатомическая схема; она не используется в игре.

## Повторение

Из корня проекта, Python с Pillow/numpy:

```text
python art/characters/side-gait-v1/build.py
python art/characters/side-gait-v1/check.py
```

Выход по умолчанию `.tools/side-gait-art/`: четыре атласа, 32 отдельные позы, рабочие части, GIF для просмотра, позы/манифест. Сборщик сам не переписывает активные игровые PNG. После художественной проверки перенести только четыре `walk/run-bare/pack.png` в игровой каталог, импортировать Godot и выполнить:

```text
godot --headless --path <проверочный checkout> --script res://scripts/tools/build_side_gait_frames.gd
python art/characters/side-gait-v1/check_resources.py
```

Ресурсный сборщик написала Qwen; Codex вернул один воспроизведённый отказ (выход после `_fail()`), затем закрепил стабильные ID после проверки побайтовой повторяемости. Он заменяет только `walk`, `walk_side`, `run_side` двух комплектов. Частота 15, длительности, 384×384, baseline 374/отступ 182, масштабы и остальные клипы сохраняются.

Для правки движения менять таблицу фаз, для новой одежды — её исходник/разметку/хеши. Не редактировать только итоговый атлас без переноса изменения в источник. Не изменять закреплённые хеши для обхода проверки. База v1 обслуживает нынешний безоружный бок; не обещает автоматическое качество других ракурсов, оружия или силуэтов.

## Границы

Сохраняется намеренная покадровость. Замена исправляет фазу конечностей; скорость физического движения не подгоняется под длину нарисованного шага. Точное отсутствие скольжения стоп по земле ещё не заявляется. Передние/задние позы и бой остаются прежними. Окончательная художественная оценка владельца — после актуальной сборки на телефоне.
