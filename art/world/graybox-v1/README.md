# WORLD-GRAYBOX-01 — проходимая схема мира

Отдельная сцена `scenes/world/world_graybox.tscn`, версия **0.21.0-world-graybox / code50**. Регион 2000×2000 м, четыре площадки городов, горный хребет, два верхних прохода и нижняя долина, пять основных дорог, три подъезда, три речные ветви. Это проверка масштаба и связей до производства окружения. География не утверждена владельцем.

Источник: [карта v0.3](../../../docs/design/world-connections-v1/README.md). Горизонтальные координаты исходника сдвигаются на −1000 м; высоты остаются в метрах. Шаг сетки 5 м, 401×401 узел, 100 участков по 40×40 ячеек, 320000 треугольников земли. Видимая сетка и её коллизия строятся из одних индексов. Карта целиком загружается в память; потоковая загрузка регионов сюда не входит.

## Воспроизведение

1. Прочитать `GODOT_CONNECTION.md` и карточку ниже; использовать Godot 4.7.2 и Python с NumPy.
2. `python art/world/graybox-v1/build.py` пересоздаёт высоты, линейные цвета, JSON дорог и копию принятого героя. Исходники карты и героя не изменяются. Хеши — `manifest.json`.
3. `node tools/build-world-graybox.mjs --baseline-root <основной checkout> --stage-only` готовит отдельный импортируемый проект. `--validate` собирает отдельную Android QA, `--release-stage` — обычные APK/EXE в отдельном staging, чтобы не перезаписывать проект выполняющегося теста. Стенд имеет собственный Android package/user directory; основной двор и Walk Preview сохраняются.
4. `node tools/run-world-graybox-checks.mjs --baseline-root <основной checkout>` проверяет реальные коллизии/героя, 16 маршрутов, обочины, EN/RU, обзор и окна 16:9/4:3. Проверять код выхода, журнал, JSON и завершение всех маршрутов. После экспорта нужна настоящая проверка установленной APK.

## Что является гипотезой

Крупные формы получены из предложенных хребтов и высот, без географического шума ради детализации. Речные долины сначала приводятся к отметкам воды, затем формируются дороги и русла. Узлы из схемы не являются готовым DEM.

Резкие углы бумажной схемы скруглены круговыми дугами. У городов/общего узла высоты дорог согласованы; часть городских площадок сдвинута на сухой берег. Исходные точки сохранены рядом с `geometry_points` в JSON. Поэтому фактические длины макета отличаются от прямых отрезков PDF. Узкие коллизионные полосы шириной 6 м задают покрытие, земляные откосы обеспечивают сход/возврат, глубокие русла остаются под мостовыми пролётами. Это геометрическая проверка, не финальная архитектура мостов.

Принятый герой 0.19.4 перенесён отдельным ресурсом без новых рисунков, изменения фаз или масштаба; исходная [опора](../../characters/accepted-traveler-v1/README.md) продолжает проходить проверку 40 хешей.

## Управление

- «Прогулка» / Tab переключает обзор и героя. Выпадающий список переносит к выбранной площадке.
- Обзор: перетаскивание вращает камеру, колесо / + / − меняет расстояние, стрелки / WASD / экранная крестовина сдвигают центр. «Весь мир» возвращает общий вид.
- Герой: WASD / крестовина — ходьба; Shift / «Бег» — бег. Правая область телефона вращает камеру. На ПК клик в мире захватывает мышь, Esc освобождает. «К площади» возвращает героя.
- EN/RU переключает язык. Меню и подсказки используют книгу UI 1.0 и общую Theme.

Границы: условные дома — проходимые объёмы, нет NPC/квестов/растительности/текстур, плавания и боевых противников. По руслу можно пройти; вода не является готовой игровой механикой. Выход за край возвращает к выбранному городу. Свободный обзор и переносы — инструменты стенда, не изменение правил карты в кампании. Художественная приёмка, окончательный размер и выбор болот/джунглей остаются открыты.
