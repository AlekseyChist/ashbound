# Бег героя — исходники кадров

**Первая версия ниже отклонена владельцем:** бег выглядит другим и более крупным персонажем. Новый проход v3 использует отдельный исходный атлас ходьбы каждого ракурса и сохраняет контрольные idle/attack ряды. Параметры масштаба теперь сверяются по анатомии; полную высоту беговой позы нельзя нормировать к стоячему росту.

20 сентября 2026. Метод: встроенный `image_gen` по навыку imagegen, с тремя существующими атласами путешественника как референсами. Генерация не заменяла локальную Ollama для кода: ресурсы анимаций и подключение пишет Ollama.

В отклонённой 0.4.0 использовались `assets/characters/courtyard/traveler-run-v1.png` (спина/лицо) и `traveler-run-spaced-v2.png` (профиль). Эти ассеты удалены из рабочего дерева после замены; исходники сохранены в коммите `0181226`. Актуальные рисунки и промпты описаны в [RUN_REDRAW_PROMPTS.md](RUN_REDRAW_PROMPTS.md). Первые кадры не считать принятой анимацией. Альфа-канал был проверен чтением PNG: фон прозрачен, несмотря на коричневые RGB-значения невидимых пикселей.

Плотная первая компоновка не дала достаточных промежутков между нижними рядами. Для профиля используется второй атлас с разнесёнными рядами. В нём генератор выдал пять рядов вместо шести, поэтому используются только проверенные восемь кадров профиля. Разметка задаётся фактическими границами рисунков, а не предполагаемой равномерной сеткой.

## Исходный запрос

Create one production transparent PNG sprite atlas for the SAME AshBound traveler in the three supplied reference atlases. References define identity, costume, colors, proportions and hand-painted dark medieval style, not poses to copy. A single portrait-format image with EXACTLY FOUR equal columns and SIX equal rows (24 separate full-body figures). Each figure fully inside its own square cell, generous transparent gutters, no overlaps. Transparent alpha background: no floor, shadows, checkerboard, labels, text or grid lines. Same messy dark hair, short dark beard, worn brown sleeveless leather jerkin with split tails over grey rolled sleeves, belt, dark trousers and brown boots. No weapons, cape, added accessories or costume changes. Natural realistic human proportions. Every figure at the same scale, centered consistently in its cell; planted soles align to a common local ground line, flying phases visibly rise only a little. Animation is vigorous RUNNING with bent elbows, opposing arm swing, forward torso lean, raised heels and a clear airborne phase, distinctly different from slow walking. All frames form coherent alternating strides, no duplicate static poses. Reading order left to right: ROWS 1 AND 2 are the 8 successive phases of one seamless BACK-VIEW run cycle directly away from the camera (face never visible). ROWS 3 AND 4 are the SAME eight phases viewed from the FRONT running directly toward camera. ROWS 5 AND 6 are the SAME eight phases in strict RIGHT-FACING side profile. Frame sequence for each view: left-foot contact, compression, push-off, airborne/pass, right-foot contact, compression, push-off, airborne/pass returning to start. Hands naturally half-closed, no punching. Stable body size and identity, consistent mild top-front lighting, eye-height game camera, detailed clean silhouette matching supplied artwork. Usable sprite sheet, not an illustration collage. Render 1024x1536 or a larger exact 2:3 portrait ratio, cells square.
